# **2.3: Combinando Condições com Operadores Lógicos (`&&` e `||`)**

Até agora, nossas decisões `if` se baseavam em uma única condição. Nesta aula, aprendemos a construir lógicas muito mais complexas e realistas combinando múltiplas condições em uma única declaração `if`, utilizando os **operadores lógicos**.

## 1\. O Problema: Condições Múltiplas com Lógica Repetida

A aula começa com um excelente cenário: aplicar a mesma regra (desconto de 8%) para duas faixas salariais que não são contínuas (salários `< 1000` e salários `> 5000`).

A abordagem inicial, usando o que aprendemos até agora, seria duplicar o código:

```go
// Abordagem funcional, mas com repetição de código
if salario < 1000.0 {
    desconto = salario * 0.08
} else if salario <= 1200.0 {
    // ...
} else if salario > 5000.0 { // <-- Repetição da lógica de 8%
    desconto = salario * 0.08
} else {
    // ...
}
```

Isso funciona, mas tem desvantagens claras:

  * **Repetição de Código (Don't Repeat Yourself - DRY):** Se a taxa de 8% mudar, você terá que alterá-la em dois lugares, o que aumenta a chance de erros.
  * **Menos Legibilidade:** A intenção ("aplicar 8% para estas duas condições") fica espalhada pelo código.

## 2\. A Solução: Operadores Lógicos

Os operadores lógicos nos permitem combinar múltiplas expressões booleanas em uma única condição.

### a) O Operador Lógico OU (`||`)

O operador `||` (conhecido como "pipe" ou "barra vertical") representa a lógica **OU**. A condição inteira será `true` se **pelo menos uma** das sub-condições for `true`.

**Resolvendo o problema do salário:**

```go
package main

import "fmt"

func main() {
	salario := 5001.0 // Teste com um valor que se encaixa na segunda parte da condição
	desconto := 0.0

	// Se o salário for MENOR que 1000 OU MAIOR que 5000...
	if salario < 1000.0 || salario > 5000.0 {
		fmt.Println("Caiu na regra dos 8%.")
		desconto = salario * 0.08
	} else if salario <= 1200.0 {
		fmt.Println("Caiu na regra dos 10%.")
		desconto = salario * 0.10
	} else {
		fmt.Println("Caiu na regra default (15%).")
		desconto = salario * 0.15
	}
	
	salarioFinal := salario - desconto
	fmt.Printf("Salário final: R$ %.2f\n", salarioFinal)
}
```

**Saída:**

```
Caiu na regra dos 8%.
Salário final: R$ 4600.92
```

Com o operador `||`, unificamos a regra em um único `if`, tornando o código mais limpo, conciso e fácil de manter.

### b) O Operador Lógico E (`&&`)

O operador `&&` (E comercial) representa a lógica **E**. A condição inteira só será `true` se, e somente se, **todas** as sub-condições forem `true`.

Isso é perfeito para cenários onde múltiplos critérios precisam ser atendidos simultaneamente. A aula usa o exemplo de tipo de contrato (CLT vs PJ).

**Exemplo Prático: Desconto por Salário E Tipo de Contrato**

```go
package main

import "fmt"

func main() {
	salario := 900.0
	tipoContrato := "PJ" // Mude para "CLT" para ver o outro resultado
	desconto := 0.0

	// Condição 1: Salário MENOR que 1000 E tipo de contrato IGUAL a "CLT"
	if salario < 1000.0 && tipoContrato == "CLT" {
		fmt.Println("Regra: CLT < 1k (8%)")
		desconto = salario * 0.08
	// Condição 2: Salário MENOR que 1000 E tipo de contrato IGUAL a "PJ"
	} else if salario < 1000.0 && tipoContrato == "PJ" {
		fmt.Println("Regra: PJ < 1k (5%)")
		desconto = salario * 0.05
	} else {
		fmt.Println("Regra: Outras (15%)")
		desconto = salario * 0.15
	}

	fmt.Printf("Salário final: R$ %.2f\n", salario - desconto)
}
```

Neste caso, para que o primeiro bloco `if` seja executado, **ambas as condições** (`salario < 1000.0` e `tipoContrato == "CLT"`) devem ser verdadeiras.

## 3\. Tabela de Verdade (Referência Rápida)

| Condição A | Condição B | A `||` B (OU) | A `&&` B (E) |
| :--- | :--- | :--- | :--- |
| `true` | `true` | `true` | `true` |
| `true` | `false` | `true` | `false` |
| `false`| `true` | `true` | `false` |
| `false`| `false`| `false`| `false` |

## 4\. Ponto de Atenção: Atribuição (`=`) vs. Comparação (`==`)

A aula reforça um ponto crucial que confunde muitos iniciantes:

  * `=` **(um sinal de igual):** É o operador de **atribuição**. Ele *define* o valor de uma variável. Ex: `tipoContrato = "CLT"`.
  * `==` **(dois sinais de igual):** É o operador de **comparação**. Ele *verifica* se dois valores são iguais e retorna `true` ou `false`. Ex: `if tipoContrato == "CLT"`.

Usar `=` dentro de um `if` é um erro comum que o compilador Go irá detectar.

## 5\. Combinando Operadores: Precedência e Parênteses

Você pode combinar múltiplos operadores lógicos em uma única expressão. É importante saber que `&&` tem precedência sobre `||` (assim como a multiplicação tem sobre a adição na matemática). Para garantir clareza e a ordem correta de avaliação, use parênteses `()`.

**Exemplo:**

```go
// Regra: Aplicar desconto se (o usuário for admin) OU (se for um usuário premium E estiver ativo)
if isAdmin || (isPremium && estaAtivo) {
    // Aplica o desconto
}
```

Os parênteses garantem que a condição `isPremium && estaAtivo` seja avaliada primeiro.
