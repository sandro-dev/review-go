# **2.4: Laços de Repetição com `for`**

Até agora, nossos programas executavam cada linha de código apenas uma vez. Nesta aula, introduzimos os **laços de repetição** (ou loops), que nos permitem executar o mesmo bloco de código repetidamente, com base em uma condição. Em Go, toda a lógica de repetição é centralizada em uma única e poderosa palavra-chave: `for`.

## 1\. O Conceito: Por que Precisamos de Laços?

Imagine que você precise imprimir os números de 1 a 10. Sem um laço, você teria que escrever:

```go
fmt.Println(1)
fmt.Println(2)
fmt.Println(3)
// ... e assim por diante até 10
```

Isso é repetitivo e impraticável. Se precisássemos ir até 1.000, seria impossível. Um laço resolve isso, permitindo que você escreva a instrução `fmt.Println` uma única vez e diga ao programa para executá-la dez vezes, mudando o número a cada vez.

## 2\. A Estrutura do Laço `for` Clássico

Go adota a sintaxe do laço `for` que é familiar para programadores de linguagens como C, Java ou C\#. Esta estrutura é composta por três partes, separadas por ponto e vírgula `;`:

`for <inicialização>; <condição>; <pós-instrução> { ... }`

Vamos decompor cada parte, usando o exemplo da aula:

```go
package main

import "fmt"

func main() {
	//    [1]         [2]         [3]
	for i := 0; i < 10; i++ {
		// [4] Bloco de código do laço
		fmt.Println("O valor de i é:", i)
	}
}
```

1.  **[1] Inicialização (`i := 0`):**

      * Esta parte é executada **apenas uma vez**, no exato momento em que o laço começa.
      * É o local perfeito para declarar e inicializar uma variável de controle (também chamada de contador ou iterador), que geralmente é nomeada `i` por convenção.

2.  **[2] Condição (`i < 10`):**

      * Esta expressão booleana é verificada **antes de cada execução** do bloco de código.
      * Se a condição for `true`, o bloco de código dentro das chaves `{}` é executado.
      * Se a condição se tornar `false`, o laço termina imediatamente e o programa continua a execução na linha seguinte ao laço.

3.  **[3] Pós-instrução (`i++`):**

      * Esta instrução é executada **ao final de cada iteração**, *depois* que o bloco de código é executado.
      * Geralmente, é usada para modificar a variável de controle, aproximando-a da condição de término.
      * `i++` é um atalho para `i = i + 1`. Ele incrementa o valor de `i` em 1.

4.  **[4] Bloco de Código:**

      * É o conjunto de instruções que será repetido enquanto a condição for verdadeira.

## 3\. Analisando o Fluxo de Execução

Vamos seguir o programa passo a passo para entender como ele imprime de 0 a 9:

| Iteração | Ação | `i` antes | Condição `i < 10`? | Executa o Bloco? | `i` depois (`i++`) | Saída |
|:--- |:---|:--- |:--- |:--- |:--- |:--- |
| **Início** | Inicialização | - | - | - | 0 | - |
| **1ª** | Verificação | 0 | `true` | Sim | 1 | `O valor de i é: 0` |
| **2ª** | Verificação | 1 | `true` | Sim | 2 | `O valor de i é: 1` |
| **3ª** | Verificação | 2 | `true` | Sim | 3 | `O valor de i é: 2` |
| ... | ... | ... | ... | ... | ... | ... |
| **10ª**| Verificação | 9 | `true` | Sim | 10 | `O valor de i é: 9` |
| **11ª**| Verificação | 10 | `false`| **Não** | - | - |
| **Fim** | O laço termina. | | | | | |

É por isso que a saída vai de 0 a 9. Quando `i` se torna 10, a condição `10 < 10` é falsa, e o laço para.

## 4\. O "Go Way": A Versatilidade do `for`

A aula introduz a forma mais comum e clássica do `for`. É importante saber que, em Go, a palavra-chave `for` é usada para **todos** os tipos de laços. Não existem `while` ou `do-while` como em outras linguagens. Veremos em aulas futuras como o `for` pode ser adaptado para esses outros cenários, mas esta estrutura de três partes é a base para a maioria das repetições controladas por um contador.

**Ponto de Atenção:** Assim como no `if`, as chaves `{}` são obrigatórias em um laço `for`, mesmo que o bloco tenha apenas uma linha.
