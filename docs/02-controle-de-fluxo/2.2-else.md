# **2.2: Expandindo o Controle de Fluxo com `else` e `else if`**

Após aprendermos a tomar uma decisão com `if`, esta aula nos ensina a criar fluxos mais completos, definindo o que deve acontecer quando a condição inicial **não** é satisfeita. Para isso, utilizamos as palavras-chave `else` e `else if`.

## 1\. O Bloco `else` - O Caminho Alternativo

Muitas vezes, uma decisão não é apenas "faça algo ou não faça nada", mas sim "se a condição for verdadeira, faça A; **senão**, faça B". A palavra-chave `else` nos dá exatamente esse poder.

### a) O Problema: Condições Opostas com Dois `if`s

A aula começa com um cenário lógico: se um veículo não é um carro, ele deve receber uma taxa diferente. Uma primeira abordagem seria usar duas declarações `if` com condições opostas. Para criar a condição oposta, usamos o **operador de negação `!`**.

  * **Operador de Negação `!`:** Este operador inverte o valor de uma expressão booleana. `!true` se torna `false`, e `!false` se torna `true`.

<!-- end list -->

```go
// Abordagem com dois 'if's (funcional, mas não ideal)
valorDoAutomovel := 1000.0
eCarro := false 

if eCarro == true { // ou simplesmente 'if eCarro'
    valorDoAutomovel += 55.50
}

if eCarro == false { // ou 'if !eCarro'
    valorDoAutomovel += 20.50
}
fmt.Println(valorDoAutomovel) // Saída: 1020.50
```

Embora funcione, esta abordagem é redundante. O programa é forçado a checar duas condições separadas, quando na verdade elas são mutuamente exclusivas.

### b) A Solução Idiomática com `else`

A palavra-chave `else` ("senão") cria um bloco de código que é executado **apenas se a condição do `if` original for `false`**. Isso torna o código mais limpo, mais legível e mais eficiente.

```go
package main

import "fmt"

func main() {
	valorDoAutomovel := 1000.0
	eCarro := false // Mude para 'true' para ver o outro resultado

	if eCarro {
		// Este bloco executa se 'eCarro' for true
		valorDoAutomovel += 55.50
	} else {
		// Este bloco executa se 'eCarro' for false
		valorDoAutomovel += 20.50
	}

	fmt.Printf("O valor final do automóvel é R$ %.2f\n", valorDoAutomovel)
}
```

**Ponto de Atenção: A Sintaxe do `else` em Go**
Como a aula demonstrou, Go tem uma regra de formatação estrita: a palavra `else` **deve** estar na mesma linha que a chave de fechamento `}` do bloco `if`.

```go
// CORRETO (Go Way)
if condicao {
    // ...
} else {
    // ...
}

// INCORRETO (Erro de compilação)
if condicao {
    // ...
}
else { // <-- ERRO!
    // ...
}
```

Isso não é apenas uma convenção de estilo; é uma regra imposta pelo compilador para garantir consistência.

## 2\. O Encadeamento com `else if` - Múltiplas Condições

E se tivermos mais de duas possibilidades? Imagine calcular taxas de imposto com base em diferentes faixas salariais. Não é apenas "salário \< 1000 ou não", mas sim "salário \< 1000?", "salário \< 1200?", etc.

Para isso, usamos a estrutura `else if`, que nos permite encadear múltiplas verificações.

### a) Exemplo Prático: Faixas Salariais

Vamos analisar o exemplo da aula, onde diferentes faixas salariais têm diferentes descontos.

```go
package main

import "fmt"

func main() {
	salario := 1201.0 // Mude este valor para testar os diferentes caminhos
	desconto := 0.0

	if salario < 1000.0 {
		// Caminho 1: Para salários abaixo de 1000
		desconto = salario * 0.08 // 8%
		fmt.Println("Caiu na primeira faixa (8%).")
	} else if salario <= 1200.0 {
		// Caminho 2: Se não for < 1000, testa se é <= 1200
		desconto = salario * 0.10 // 10%
		fmt.Println("Caiu na segunda faixa (10%).")
	} else {
		// Caminho 3 (Default): Se nenhuma das condições acima for atendida
		desconto = salario * 0.15 // 15%
		fmt.Println("Caiu na faixa default (15%).")
	}

	salarioFinal := salario - desconto
	fmt.Printf("Salário original: R$ %.2f\n", salario)
	fmt.Printf("Desconto: R$ %.2f\n", desconto)
	fmt.Printf("Salário final: R$ %.2f\n", salarioFinal)
}
```

### b) Como Funciona o Fluxo

Em uma cadeia `if-else if-else`, o Go executa as verificações em ordem, de cima para baixo, e **para na primeira condição que for verdadeira**.

1.  O Go testa a primeira condição (`salario < 1000.0`).
2.  Se for `true`, ele executa o bloco correspondente e **ignora todo o resto da cadeia** (`else if` e `else`).
3.  Se for `false`, ele passa para a próxima condição no `else if` (`salario <= 1200.0`).
4.  Se esta for `true`, ele executa esse bloco e ignora o `else` final.
5.  Se todas as condições `if` e `else if` forem `false`, o bloco `else` final é executado como um "caminho padrão" ou "catch-all".

Apenas **um** bloco de código em toda a cadeia será executado.

## 3\. Resumo das Estruturas Condicionais

| Estrutura | Uso |
| :--- | :--- |
| **`if`** | Executa um bloco de código se uma única condição for verdadeira. |
| **`if-else`** | Executa um de dois blocos de código. Um para quando a condição é verdadeira, outro para quando é falsa. |
| **`if-else if-else`** | Executa um entre múltiplos blocos de código. Ideal para testar uma série de condições mutuamente exclusivas. |
