# **2.5: Aprofundando Laços `for`: `break` e `continue` para controle de fluxo**

Nesta aula, evoluímos nosso conhecimento sobre o laço `for`, saindo de um simples contador numérico para uma aplicação prática: iterar sobre os caracteres de uma string. Também aprendemos a manipular o fluxo de execução de um laço com as instruções `break` e `continue`.

## 1\. Iterando sobre uma String

Um dos usos mais comuns para um laço é percorrer uma coleção de dados. Uma string, em sua essência, é uma coleção (ou sequência) de caracteres.

### a) Descobrindo o Tamanho com `len()`

Para saber quantas vezes nosso laço precisa rodar, primeiro precisamos saber o tamanho da string. Em Go, usamos a função nativa `len()` para isso.

  * **Função `len()`:** Quando aplicada a uma string, `len()` retorna o número de **bytes** que a compõem. Para strings com caracteres simples (ASCII, como no alfabeto português sem acentos), o número de bytes é igual ao número de caracteres.

<!-- end list -->

```go
package main

import "fmt"

func main() {
	texto := "palavra"
	quantidade := len(texto)

	fmt.Printf("A string '%s' tem %d caracteres.\n", texto, quantidade)
}
```

**Saída:**

```
A string 'palavra' tem 7 caracteres.
```

### b) O Laço `for` Clássico para Strings

Agora, podemos combinar a estrutura `for` com a função `len()` para criar um laço que passa por cada caractere.

```go
texto := "palavra"
// O laço vai de i = 0 até i < 7 (ou seja, i = 6)
for i := 0; i < len(texto); i++ {
    // Código para processar cada caractere
}
```

### c) Acessando Caracteres por Índice e a "Pegadinha" do Tipo

Para acessar um caractere individual em uma string, usamos a sintaxe de colchetes `[]` com um índice. É crucial lembrar que a indexação em Go (e na maioria das linguagens) começa em **zero**.

  * `texto[0]` é o primeiro caractere (`'p'`)
  * `texto[1]` é o segundo caractere (`'a'`)
  * ...
  * `texto[6]` é o último caractere (`'a'`)

Como a aula demonstrou, se tentarmos imprimir `texto[i]` diretamente, não veremos a letra, mas sim um número.

  * **Por quê?** Acessar uma string por índice em Go (`texto[i]`) não retorna uma nova string de um caractere. Ele retorna um `byte` (que é um alias para `uint8`), o número que representa aquele caractere na tabela de codificação (neste caso, ASCII/UTF-8).

Para resolver isso, precisamos converter explicitamente esse `byte` de volta para uma `string`, como foi feito na aula:

```go
package main

import "fmt"

func main() {
	texto := "palavra"

	for i := 0; i < len(texto); i++ {
		// texto[i] retorna um byte (número)
		// string(texto[i]) converte esse byte para uma string
		letra := string(texto[i])
		fmt.Printf("Índice %d: %s\n", i, letra)
	}
}
```

**Saída:**

```
Índice 0: p
Índice 1: a
Índice 2: l
Índice 3: a
Índice 4: v
Índice 5: r
Índice 6: a
```

## 2\. Controlando o Fluxo Dentro do Laço

Às vezes, não queremos que o laço execute todas as suas iterações ou que execute todo o código dentro do bloco em cada iteração. Go nos dá duas ferramentas para isso.

### a) `break`: Saindo Antecipadamente do Laço

A palavra-chave `break` **termina imediatamente** a execução do laço `for` em que se encontra. O programa continua a execução na primeira linha *após* o bloco do laço.

É útil quando você encontra o que estava procurando e não precisa mais continuar iterando.

**Exemplo:** Pare de processar a palavra assim que encontrar a letra "r".

```go
package main

import "fmt"

func main() {
	texto := "palavra"
	fmt.Println("Procurando pela letra 'r' para parar...")

	for i := 0; i < len(texto); i++ {
		letra := string(texto[i])

		if letra == "r" {
			fmt.Println("Encontrei a letra 'r'! Saindo do laço.")
			break // Termina o laço aqui
		}

		fmt.Println("Processando letra:", letra)
	}

	fmt.Println("Fim do programa.")
}
```

**Saída:**

```
Procurando pela letra 'r' para parar...
Processando letra: p
Processando letra: a
Processando letra: l
Processando letra: a
Processando letra: v
Encontrei a letra 'r'! Saindo do laço.
Fim do programa.
```

Note que as letras "r" e "a" (final) não foram impressas dentro do laço.

### b) `continue`: Pulando para a Próxima Iteração

A palavra-chave `continue` **interrompe a iteração atual** e pula imediatamente para a próxima. O código restante dentro do bloco do laço para a iteração atual não é executado.

É útil quando você quer ignorar um item específico, mas continuar processando os outros.

**Exemplo:** Processe a palavra, mas ignore a letra "r".

```go
package main

import "fmt"

func main() {
	texto := "palavra"
	fmt.Println("Processando a palavra, mas pulando a letra 'r'...")

	for i := 0; i < len(texto); i++ {
		letra := string(texto[i])

		if letra == "r" {
			fmt.Println("(Pulando a letra 'r')")
			continue // Pula o resto desta iteração
		}
		
		// Esta linha não será executada quando a letra for 'r'
		fmt.Println("Processando letra:", letra) 
	}
	
	fmt.Println("Fim do laço.")
}
```

**Saída:**

```
Processando a palavra, mas pulando a letra 'r'...
Processando letra: p
Processando letra: a
Processando letra: l
Processando letra: a
Processando letra: v
(Pulando a letra 'r')
Processando letra: a
Fim do laço.
```

## 3\. Resumo Comparativo

| Instrução | Ação | Efeito no Laço |
| :--- | :--- | :--- |
| **`break`** | Interrompe tudo. | O laço é **terminado** completamente. |
| **`continue`**| Interrompe o passo atual. | A iteração atual é **interrompida**; o laço continua com a próxima iteração. |
