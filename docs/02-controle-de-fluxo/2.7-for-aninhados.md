# **2.7: Laços Aninhados - Um `for` Dentro de Outro `for`**

Nesta aula, expandimos a utilidade dos laços de repetição ao explorar o conceito de **laços aninhados** (ou *nested loops*). Isso ocorre quando colocamos uma estrutura `for` completamente dentro do bloco de outra estrutura `for`. O exemplo prático de criar uma tabuada é a maneira perfeita de visualizar esse conceito em ação.

## 1\. O Conceito: Como Funciona um Laço Aninhado?

Imagine um relógio com ponteiros de minutos e segundos. O ponteiro dos segundos (o laço interno) precisa dar uma volta completa (60 passos) para que o ponteiro dos minutos (o laço externo) se mova apenas um passo.

A lógica é a mesma para os laços aninhados:

  * **Laço Externo:** Controla a iteração principal.
  * **Laço Interno:** Para **cada uma** das iterações do laço externo, o laço interno executa seu ciclo **completo**, do início ao fim.

## 2\. Exemplo Prático: Construindo a Tabuada

A aula demonstra isso de forma brilhante ao construir uma tabuada de 1 a 10.

  * O **laço externo** será responsável por iterar sobre o "número base" da tabuada (de 1 a 10).
  * O **laço interno** será responsável por iterar sobre o "multiplicador" (também de 1 a 10).

### a) O Código Analisado

```go
package main

import "fmt"

func main() {
	fmt.Println("--- Tabuada de 1 a 10 ---")

	// Laço Externo: Itera sobre o número base da tabuada.
	// Começa em 1 e vai até 10.
	for numBase := 1; numBase <= 10; numBase++ {
		
		fmt.Println("\n--- Tabuada do", numBase, "---")

		// Laço Interno: Para cada 'numBase', este laço roda 10 vezes.
		// Itera sobre o número que vai multiplicar a base.
		for multiplicado := 1; multiplicado <= 10; multiplicado++ {
			
			resultado := numBase * multiplicado

			// Imprime a linha da tabuada formatada
			fmt.Println(numBase, "x", multiplicado, "=", resultado)
		}
	}
}
```

### b) Rastreando o Fluxo de Execução

Vamos seguir as primeiras iterações para entender o fluxo:

1.  **Laço Externo começa:** `numBase` é `1`.
2.  **Laço Interno começa:**
      * `multiplicado` é `1`. Imprime `1 x 1 = 1`.
      * `multiplicado` é `2`. Imprime `1 x 2 = 2`.
      * ...
      * `multiplicado` é `10`. Imprime `1 x 10 = 10`.
3.  **Laço Interno termina.**
4.  **Laço Externo vai para a próxima iteração:** `numBase` agora é `2`.
5.  **Laço Interno começa DE NOVO:**
      * `multiplicado` é `1`. Imprime `2 x 1 = 2`.
      * `multiplicado` é `2`. Imprime `2 x 2 = 4`.
      * ...
      * `multiplicado` é `10`. Imprime `2 x 10 = 20`.
6.  **Laço Interno termina.**
7.  ... e o processo continua até `numBase` ser `10`.

## 3\. Flexibilidade e Boas Práticas

A aula destaca pontos importantes sobre a escrita de laços:

  * **Nomes de Variáveis Descritivos:** Você não está preso a usar `i`, `j`, `k` como nomes de variáveis de laço. Usar nomes claros como `numBase` e `multiplicado` torna o código muito mais legível e fácil de entender.
  * **Iniciando de `1`:** O laço não precisa sempre começar de `0`. Para a tabuada, começar de `1` faz muito mais sentido. Você tem total controle sobre as três cláusulas do `for`.

## 4\. Bônus: A Versatilidade do `fmt.Println`

A aula também mostra implicitamente como a função `fmt.Println` é flexível. Você pode passar múltiplos argumentos separados por vírgula, e a função irá imprimi-los em sequência, separados por um espaço padrão.

```go
// A função recebe 5 argumentos: um número, uma string, outro número, outra string, e um resultado.
fmt.Println(numBase, "x", multiplicado, "=", resultado)
```

## 5\. Onde os Laços Aninhados São Usados?

Este padrão é extremamente comum e útil em vários cenários:

  * **Processamento de Matrizes ou Grades (2D):** Imagine uma planilha ou um tabuleiro de xadrez. Você usaria um laço externo para as linhas e um interno para as colunas.
  * **Combinações:** Encontrar todos os pares possíveis entre dois conjuntos de dados.
  * **Renderização Gráfica:** Percorrer cada pixel de uma tela (laço externo para a coordenada Y, laço interno para a coordenada X).
  * **Estruturas de Dados Complexas:** Iterar sobre uma lista de usuários (laço externo) e, para cada usuário, iterar sobre sua lista de permissões (laço interno).
