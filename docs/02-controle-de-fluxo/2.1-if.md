# **2.1: Controle de Fluxo - Tomando Decisões com `if`**

Esta aula introduz o conceito de **controle de fluxo**, que é a capacidade de um programa executar diferentes blocos de código com base em certas condições. Abandonamos a execução puramente linear (de cima para baixo) para criar lógicas mais inteligentes e dinâmicas, que podem tomar decisões. A ferramenta fundamental para isso é a declaração `if`.

## 1\. O Que é Controle de Fluxo?

Por padrão, um programa é executado instrução por instrução, da primeira à última linha. O controle de fluxo permite quebrar essa sequência. Usando declarações condicionais, podemos dizer ao programa: "**Se** uma condição for verdadeira, execute este caminho; caso contrário, siga outro caminho (ou não faça nada)".

O exemplo abordado na aula é perfeito para ilustrar isso: um funcionário só recebe um bônus **se** o seu salário atender a um critério específico. Essa decisão, esse desvio no fluxo, é o cerne do que estamos aprendendo.

## 2\. A Estrutura da Declaração `if` e os Operadores de Comparação

A sintaxe do `if` em Go é limpa e direta. Ela avalia uma condição e, se a condição for `true`, executa o bloco de código dentro das chaves `{}`.

**Sintaxe Básica:**

```go
if <condição> {
    // Bloco de código a ser executado se a condição for verdadeira
}
```

  * **`if`:** A palavra-chave reservada que inicia a declaração condicional.
  * **`<condição>`:** Uma expressão que **deve** resultar em um valor booleano (`true` ou `false`). Para criar essas condições, usamos os operadores de comparação:

| Operador | Descrição | Exemplo de Uso |
| :--- | :--- | :--- |
| `==` | Igual a | `idade == 18` |
| `!=` | Diferente de | `status != "Concluído"`|
| `<` | Menor que | `estoque < 10` |
| `>` | Maior que | `temperatura > 30.0` |
| `<=` | Menor ou igual a | `salario <= 1000.0` |
| `>=` | Maior ou igual a | `nota >= 7.0` |

## 3\. Exemplo Prático: O Impacto da Inclusividade (`<` vs. `<=`)

A escolha do operador correto é crucial para definir as regras de negócio do seu programa. Vamos analisar a regra: "Funcionários que ganham R$ 1000.00 ou menos recebem o bônus". Veja como a escolha do operador muda o resultado para um funcionário que ganha exatamente R$ 1000.00.

```go
package main

import "fmt"

func main() {
	salario := 1000.0
	salarioFinal := salario

	// Teste com o operador '<' (menor que)
	if salario < 1000.0 {
		// Esta condição é FALSE, pois 1000 não é menor que 1000.
		// O bloco não executa.
		salarioFinal += 100.0
	}
	fmt.Printf("Com '<', o salário de R$ %.2f resulta em R$ %.2f\n", salario, salarioFinal)

	// Resetando a variável para o novo teste
	salarioFinal = salario
	
	// Teste com o operador '<=' (menor ou IGUAL a)
	if salario <= 1000.0 {
		// Esta condição é TRUE, pois 1000 é igual a 1000.
		// O bloco executa.
		salarioFinal += 100.0
	}
	fmt.Printf("Com '<=', o salário de R$ %.2f resulta em R$ %.2f\n", salario, salarioFinal)
}
```

**Saída:**

```
Com '<', o salário de R$ 1000.00 resulta em R$ 1000.00
Com '<=', o salário de R$ 1000.00 resulta em R$ 1100.00
```

Isso mostra como a escolha entre um operador exclusivo (`<`) e um inclusivo (`<=`) altera drasticamente o comportamento do programa em suas "condições de contorno" (boundary conditions).

## 4\. A Verdade Universal do `if`: Tudo é Booleano

A declaração `if` não se limita a comparações numéricas. Sua verdadeira função é avaliar se uma expressão resulta em `true`. Uma variável do tipo `bool` já contém, por si só, um valor `true` ou `false` e pode ser usada diretamente.

  * `if salario <= 1000` é uma **expressão** que o Go primeiro resolve para `true` ou `false`, e então o `if` usa esse resultado.
  * `if eCarro` é uma **variável** que já contém `true` ou `false`, então o `if` a usa diretamente.

**Exemplo Prático (Carro vs. Moto):**

```go
package main

import "fmt"

func main() {
	valorDoAutomovel := 1000.0
	eCarro := true // Mude para 'false' para ver o outro resultado

	// Lê-se: "Se 'eCarro' for verdadeiro..."
	if eCarro { 
		// O bloco só executa se a variável 'eCarro' for true.
		valorDoAutomovel += 55.50 // Adiciona a taxa do carro
	}

	fmt.Printf("O valor final do automóvel é R$ %.2f\n", valorDoAutomovel)
}
```

> **Nota do Especialista:** Uma prática comum e recomendada em Go é usar a variável booleana diretamente (`if eCarro`), em vez de ser explícito demais (`if eCarro == true`). Ambas as formas funcionam, mas a primeira é mais concisa e idiomática.

## 5\. As Regras Idiomáticas do Go (O "Go Way")

As aulas destacaram regras muito importantes que diferenciam o Go de outras linguagens e são impostas pelo compilador e pelo formatador `gofmt`.

1.  **Chaves `{}` são Obrigatórias:** Em Go, as chaves são sempre obrigatórias para um bloco `if`, mesmo que ele contenha apenas uma linha de código. Isso evita uma classe comum de bugs e torna o código universalmente mais legível.
2.  **A Posição da Chave de Abertura `{`:** A chave de abertura `{` **deve** estar na mesma linha que a declaração `if`. Colocá-la na linha seguinte resultará em um erro de compilação. Isso garante consistência visual em todo o código Go.

## 6\. Dica de Produtividade: Operadores de Atribuição Composta

Uma forma mais curta e comum de modificar o valor de uma variável com base em seu próprio valor é usando operadores de atribuição composta.

| Forma Longa | Forma Curta (Composta) | Descrição |
| :--- | :--- | :--- |
| `x = x + y`| `x += y` | Adiciona `y` a `x` |
| `x = x - y`| `x -= y` | Subtrai `y` de `x` |
| `x = x * y`| `x *= y` | Multiplica `x` por `y` |
| `x = x / y`| `x /= y` | Divide `x` por `y` |

Usar `salarioFinal += 100.0` é o jeito idiomático ("Go Way") de escrever `salarioFinal = salarioFinal + 100.0`.
