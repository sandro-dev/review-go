# **6.2: Agrupando Dados com Structs**

Com nosso ambiente de desenvolvimento local e um projeto baseado em módulos configurados, estamos prontos para ir além dos tipos de dados primitivos (`int`, `string`, etc.). Nesta aula, aprendemos a criar nossos próprios tipos de dados compostos usando `structs`.

## 1\. O "Porquê": A Necessidade de Agrupar Dados

No mundo real, os dados raramente existem de forma isolada. Um endereço não é apenas uma rua; é uma combinação de rua, número, cidade, CEP, etc. Tentar representar isso com variáveis separadas é confuso e propenso a erros:

```go
// Forma ruim: dados espalhados
var rua string = "Rua X"
var numero int = 15
var cidade string = "Campo Grande"
```

Uma **struct** (abreviação de *structure*, ou estrutura) é a solução de Go para esse problema. Ela nos permite agrupar múltiplos campos de dados (de tipos iguais ou diferentes) em uma única unidade lógica, criando um **novo tipo de dado**.

## 2\. Definindo uma Struct: O Blueprint

Para definir uma struct, usamos a palavra-chave `type` para criar um novo tipo, seguido pelo nome do tipo e a palavra-chave `struct` com os campos definidos entre chaves `{}`. Pense nisso como criar uma "planta" ou um "molde" para seus dados.

**Sintaxe:**

```go
type NomeDaStruct struct {
    NomeDoCampo1 TipoDoCampo1
    NomeDoCampo2 TipoDoCampo2
    // ...
}
```

**Exemplo Prático (da aula):**

```go
package main

import "fmt"

// Define um novo tipo chamado 'Endereco'.
// Este tipo agrupa três campos: Rua, Numero e Cidade.
type Endereco struct {
	Rua    string
	Numero int
	Cidade string
}

// ...
```

**O "Go Way":** A convenção em Go é nomear os tipos com `CamelCase` (a primeira letra maiúscula), como `Endereco`. Isso também indica que o tipo é **exportado**, ou seja, ele pode ser usado por outros pacotes (veremos isso mais tarde).

## 3\. Criando (Instanciando) uma Struct

Uma vez que temos o "molde" (`type Endereco`), podemos criar "objetos" concretos a partir dele. Esse processo é chamado de **instanciação**. A forma mais comum de fazer isso é usando um **struct literal**.

**Sintaxe:** `variavel := NomeDaStruct{Campo1: valor1, Campo2: valor2, ...}`

```go
// (dentro da função main)

// Instancia uma variável do tipo Endereco e preenche seus campos.
meuEndereco := Endereco{
    Rua:    "Rua X",
    Numero: 15,
    Cidade: "Campo Grande", // A vírgula no final é idiomática e recomendada em Go!
}

fmt.Println("Meu endereço é:", meuEndereco)
```

**Saída:**

```
Iniciando
Meu endereço é: {Rua X 15 Campo Grande}
```

**Pontos de Atenção (da aula):**

  * **Variável vs. Tipo:** Go consegue diferenciar o nome da variável (`meuEndereco`) do nome do tipo (`Endereco`). A convenção é usar `camelCase` para nomes de variáveis.
  * **Vírgula Final:** O formatador do Go exige uma vírgula após o último campo em um struct literal de múltiplas linhas. Isso facilita a adição, remoção ou reordenação de campos sem causar erros de sintaxe na linha anterior.

## 4\. Acessando e Modificando Campos

Para ler ou alterar o valor de um campo específico de uma instância de struct, usamos o **operador ponto (`.`)**.

**Sintaxe:** `nomeDaVariavel.NomeDoCampo`

```go
// (continuação da função main)

// Lendo o valor de um campo
fmt.Println("A cidade é:", meuEndereco.Cidade) // Saída: A cidade é: Campo Grande

// Modificando o valor de um campo
meuEndereco.Numero = 18
fmt.Println("O número foi atualizado para:", meuEndereco.Numero) // Saída: O número foi atualizado para: 18

fmt.Println("Endereço atualizado:", meuEndereco) // Saída: {Rua X 18 Campo Grande}
```

## 5\. Código Completo da Aula

```go
// main.go
package main

import "fmt"

// Definição da Struct (o "blueprint")
type Endereco struct {
	Rua    string
	Numero int
	Cidade string
}

func main() {
	fmt.Println("Iniciando")

	// 1. Instanciação da Struct
	meuEndereco := Endereco{
		Rua:    "Rua X",
		Numero: 15,
		Cidade: "Campo Grande",
	}
	fmt.Println("Endereço inicial:", meuEndereco)

	// 2. Acessando e Modificando um Campo
	fmt.Println("Número atual:", meuEndereco.Numero)
	meuEndereco.Numero = 18 // Modificação
	fmt.Println("Número novo:", meuEndereco.Numero)

	fmt.Println("Endereço final:", meuEndereco)
}
```

## 6\. O "Go Way": O Valor Zero de uma Struct

O que acontece se você apenas declarar uma variável do tipo struct sem inicializá-la? Go garante que ela terá um **valor zero**. O valor zero de uma struct é uma struct onde **cada um de seus campos** é inicializado com seu respectivo valor zero.

```go
var enderecoVazio Endereco
fmt.Printf("Endereço vazio (valor zero): %#v\n", enderecoVazio)
// Saída: Endereço vazio (valor zero): main.Endereco{Rua:"", Numero:0, Cidade:""}
```

Isso é extremamente útil, pois garante que você sempre terá uma struct válida para trabalhar, sem o risco de encontrar um erro de "ponteiro nulo" (null pointer) como em outras linguagens.
