# **4.1: Organizando Código com Funções**

Até agora, todo o nosso código residiu dentro da função especial `main`. Nesta aula, aprendemos a criar nossas próprias **funções** para organizar o código, torná-lo reutilizável e muito mais fácil de manter.

## 1\. O "Porquê" das Funções: Organização e Reutilização

A função `main` é o ponto de entrada obrigatório de qualquer programa executável em Go. No entanto, colocar toda a lógica da sua aplicação dentro dela é uma má prática que leva a um código longo, confuso e difícil de dar manutenção (conhecido como "código macarrônico").

As funções são a principal ferramenta para evitar isso. Elas nos permitem:

  * **Organização:** Quebrar um problema grande em pedaços menores e mais gerenciáveis. Cada função pode ser responsável por uma única tarefa bem definida (o **Princípio da Responsabilidade Única**).
  * **Reutilização:** Escrever um bloco de código uma vez e chamá-lo de vários lugares diferentes, evitando a duplicação de código.
  * **Manutenibilidade:** Se um bug for encontrado em uma tarefa específica, você só precisa corrigi-lo em um lugar: dentro da função responsável por aquela tarefa.
  * **Abstração:** Esconder a complexidade. A função `main` pode chamar `calcularImpostos()`, sem precisar saber *como* os impostos são calculados, apenas que a função faz o que promete.

> **Nota do Especialista:** Como a aula menciona, em programação orientada a objetos (OOP), funções associadas a uma classe ou struct são chamadas de **métodos**. Em Go, o conceito é muito similar. Uma função é um bloco de código reutilizável; um método é uma função associada a um tipo específico.

## 2\. A Anatomia de uma Função em Go

Para criar uma função, seguimos uma sintaxe simples e clara:

```go
// 1. Palavra-chave `func` que indica o início de uma declaração de função.
// |
// |     2. Nome da função, que segue a convenção camelCase para funções não exportadas.
// |     |
// |     |                3. Lista de parâmetros entre parênteses. Pode ser vazia.
// v     v                v
func imprimeMensagem() {
	// 4. Corpo da função: o código a ser executado, delimitado por chaves {}.
	fmt.Println("Olá de dentro da função!")
} // <- 5. Fim do corpo da função.
```

## 3\. Declarando vs. Chamando uma Função

Criar (declarar) uma função não faz nada por si só. O código dentro dela só será executado quando a função for **chamada** (ou invocada).

Como a aula demonstrou, se você apenas mover o código para uma nova função sem chamá-la de `main`, nada será impresso no console.

**Sintaxe da Chamada:** `nomeDaFuncao()`

```go
package main

import "fmt"

// 1. A função é declarada aqui.
func imprimeMensagemEspecial() {
	fmt.Println("🕰️ 世界") // Imprime a mensagem
}

func main() {
	fmt.Println("Início da função main.")
	
	// 2. A função é CHAMADA aqui. O fluxo do programa "pula" para dentro de imprimeMensagemEspecial,
	//    executa seu código, e depois retorna para continuar a execução de main.
	imprimeMensagemEspecial()

	fmt.Println("Fim da função main.")
}
```

**Saída:**

```
Início da função main.
🕰️ 世界
Fim da função main.
```

## 4\. Tornando Funções Dinâmicas com Parâmetros

Uma função que faz sempre a mesma coisa é útil, mas o verdadeiro poder vem de torná-las dinâmicas, capazes de operar com dados diferentes a cada chamada. Fazemos isso através de **parâmetros**.

  * **Parâmetro:** É a "variável" que a função declara que espera receber. Fica na definição da função.
  * **Argumento:** É o "valor" real que você passa para a função quando a chama.

**Sintaxe do Parâmetro:** `(nomeDoParametro TipoDoParametro)`

```go
package main

import "fmt"

// Esta função agora espera receber um parâmetro chamado 'mensagem' do tipo 'string'.
func imprimeMensagemCustomizada(mensagem string) {
	fmt.Println("A mensagem recebida é:", mensagem)
}

func main() {
	// Chamando a mesma função com argumentos diferentes.
	imprimeMensagemCustomizada("Mensagem X")
	imprimeMensagemCustomizada("Mensagem Y")
}
```

**Saída:**

```
A mensagem recebida é: Mensagem X
A mensagem recebida é: Mensagem Y
```

## 5\. Funções Podem Conter Lógica Complexa

Uma função não se limita a executar uma única instrução. Ela pode conter qualquer lógica que você precise, incluindo condicionais, laços e operações com variáveis.

O exemplo da aula, que adiciona um prefixo à mensagem, ilustra isso perfeitamente.

```go
// Esta função recebe uma mensagem e adiciona uma saudação antes de imprimir.
func saudar(mensagem string) {
	// Lógica interna da função
	saudacaoCompleta := "Bom dia! " + mensagem
	
	fmt.Println(saudacaoCompleta)
}

func main() {
	saudar("O dia está lindo.")
	saudar("Vamos programar em Go!")
}
```

**Saída:**

```
Bom dia! O dia está lindo.
Bom dia! Vamos programar em Go!
```

Agora, a função `saudar` tem uma responsabilidade clara: receber uma mensagem e apresentá-la como uma saudação.
