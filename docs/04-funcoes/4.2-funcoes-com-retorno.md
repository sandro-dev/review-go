# **4.2: Funções com Retorno - Produzindo Valores**

Na aula anterior, nossas funções executavam ações, como imprimir uma mensagem no console. Elas eram como "procedimentos". Agora, vamos criar funções que agem como "calculadoras": elas recebem dados (parâmetros), processam-nos e **retornam um resultado** que pode ser usado em outras partes do nosso código.

## 1\. O "Porquê" do Retorno de Funções

O objetivo de uma função com retorno é encapsular um cálculo ou uma lógica e produzir um valor. Isso nos permite:

  * **Obter Resultados:** Realizar uma soma, buscar um dado, formatar um texto e obter o resultado para usar em uma variável.
  * **Composição:** Usar o resultado de uma função como entrada para outra, criando lógicas mais complexas.
  * **Testabilidade:** É muito mais fácil testar uma função que retorna um valor (ex: `soma(1, 2)` deve retornar `3`) do que uma que apenas imprime algo na tela.

## 2\. A Anatomia de uma Função com Retorno

Para declarar que uma função retornará um valor, adicionamos o **tipo do retorno** após a lista de parâmetros.

**Sintaxe:** `func nomeDaFuncao(param1 Tipo1, ...) TipoDoRetorno { ... }`

  * **`TipoDoRetorno`:** Esta é a parte nova. Ela define o "contrato" da função, prometendo que, ao final de sua execução, ela devolverá um valor daquele tipo.

## 3\. A Palavra-Chave `return`

Dentro da função, a palavra-chave `return` tem duas responsabilidades:

1.  Especifica qual valor deve ser enviado de volta para quem chamou a função.
2.  **Termina imediatamente** a execução da função. Qualquer código dentro da função após uma instrução `return` não será executado.

## 4\. Exemplo Prático Completo: A Função `soma`

A aula demonstra isso perfeitamente com uma função que soma dois números.

```go
package main

import "fmt"

// A função 'soma' recebe dois parâmetros do tipo 'int'
// e promete retornar um valor também do tipo 'int'.
func soma(numero1 int, numero2 int) int {
	// 1. Executa a lógica interna
	resultadoDaSoma := numero1 + numero2

	// 2. Usa 'return' para enviar o resultado de volta
	return resultadoDaSoma
}

func main() {
	// 3. Chamamos a função 'soma' com os argumentos 1 e 2.
	// O valor retornado pela função (3) é capturado e armazenado na variável 'resultado'.
	resultado := soma(1, 2)

	// 4. Usamos o valor que a função nos deu.
	fmt.Println("O resultado da soma é:", resultado) // Saída: 3
}
```

## 5\. O Fluxo de Dados: Entrada -\> Processamento -\> Saída

É crucial entender como os dados fluem:

1.  `main` chama `soma` com os **argumentos** `1` e `2`.
2.  Os valores `1` e `2` são copiados para os **parâmetros** `numero1` e `numero2` dentro da função `soma`.
3.  `soma` executa sua lógica interna: `1 + 2`, chegando ao valor `3`.
4.  A instrução `return 3` é executada. A função `soma` encerra sua execução.
5.  O valor `3` é "enviado de volta" para o local exato onde `soma` foi chamada em `main`.
6.  A linha de código em `main` se torna, efetivamente, `resultado := 3`.
7.  A variável `resultado` agora contém o valor `3`, pronto para ser usado.

## 6\. O "Go Way": Retornos Nomeados (Named Return Values)

Go oferece uma sintaxe alternativa que pode, em alguns casos, tornar o código mais claro, especialmente em funções mais complexas. São os "retornos nomeados".

Você pode dar um nome à variável de retorno na própria assinatura da função. Essa variável já estará declarada e pronta para ser usada dentro da função.

**Reescrevendo a função `soma` com retorno nomeado:**

```go
// A variável 'resultado' do tipo 'int' já é declarada na assinatura.
func somaComRetornoNomeado(numero1 int, numero2 int) (resultado int) {
	resultado = numero1 + numero2
	
	// Um 'return' vazio (bare return) retorna automaticamente o valor atual
	// da variável de retorno nomeada.
	return
}

func main() {
    resultado := somaComRetornoNomeado(5, 5)
    fmt.Println("O resultado (com retorno nomeado) é:", resultado) // Saída: 10
}
```

**Vantagens:**

  * **Documentação:** A assinatura da função já documenta o que ela retorna.
  * **Clareza:** Em funções longas, fica claro qual variável está sendo preparada para o retorno.

Embora úteis, use retornos nomeados com moderação. Para funções curtas e simples como `soma`, a primeira forma (sem nomear o retorno) é geralmente mais legível.
