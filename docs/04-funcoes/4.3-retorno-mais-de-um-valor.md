# **4.3: Funções com Múltiplos Retornos**

Em Go, uma função não está limitada a retornar apenas um único valor. Esta é uma característica de design fundamental que a diferencia de muitas outras linguagens populares. A capacidade de retornar múltiplos valores é usada extensivamente em Go, principalmente para o padrão de tratamento de erros `(valor, erro)`.

## 1\. A Anatomia de uma Função com Múltiplos Retornos

Para que uma função retorne mais de um valor, a sintaxe da sua **assinatura** é ligeiramente modificada.

  * **Assinatura da Função:** Como a aula define, é o conjunto que compreende o nome da função, seus parâmetros e seus tipos de retorno.

**Sintaxe:** `func nomeDaFuncao(param1 Tipo1, ...) (RetornoTipo1, RetornoTipo2, ...)`

A diferença crucial é que os tipos de retorno múltiplos **devem** ser envolvidos por parênteses `()`.

## 2\. Exemplo Prático: As Quatro Operações Matemáticas

A aula constrói um exemplo excelente e claro: uma única função que recebe dois números e retorna os resultados das quatro operações básicas.

### a) A Declaração da Função

```go
package main

import "fmt"

// A assinatura da função 'operacoes' declara que ela recebe dois inteiros
// e retorna QUATRO valores, todos do tipo inteiro.
func operacoes(numero1 int, numero2 int) (int, int, int, int) {
	soma := numero1 + numero2
	subtracao := numero1 - numero2
	multiplicacao := numero1 * numero2
    
    // Tratamento para evitar divisão por zero (boa prática)
    var divisao int
    if numero2 != 0 {
        divisao = numero1 / numero2
    }

	// A instrução 'return' deve fornecer um valor para cada tipo de retorno
	// na ordem exata em que foram declarados na assinatura.
	return soma, subtracao, divisao, multiplicacao
}
```

### b) Chamando a Função e Capturando os Resultados

Ao chamar uma função que retorna múltiplos valores, você precisa fornecer variáveis suficientes no lado esquerdo do operador `:=` (ou `=`) para "capturar" cada um dos valores retornados.

```go
func main() {
	// Chamamos a função e as variáveis são preenchidas na ordem:
	// soma <- primeiro retorno
	// sub  <- segundo retorno
	// div  <- terceiro retorno
	// mult <- quarto retorno
	soma, sub, div, mult := operacoes(10, 2)

	fmt.Println("Resultados para 10 e 2:")
	fmt.Printf("Soma: %d\n", soma)
	fmt.Printf("Subtração: %d\n", sub)
	fmt.Printf("Divisão: %d\n", div)
	fmt.Printf("Multiplicação: %d\n", mult)
    
    fmt.Println("\n--- Exemplo com 1 e 2 ---")
    s, sb, d, m := operacoes(1, 2)
    fmt.Printf("Soma: %d, Subtração: %d, Divisão: %d, Multiplicação: %d\n", s, sb, d, m)
}
```

**Saída:**

```
Resultados para 10 e 2:
Soma: 12
Subtração: 8
Divisão: 5
Multiplicação: 20

--- Exemplo com 1 e 2 ---
Soma: 3, Subtração: -1, Divisão: 0, Multiplicação: 2
```

Note que no segundo exemplo, a divisão `1 / 2` resulta em `0`, pois é uma divisão de inteiros que trunca a parte decimal.

## 3\. Tipos de Retorno Heterogêneos

Como a aula corretamente aponta, os valores de retorno não precisam ser todos do mesmo tipo. Você pode misturar `int`, `string`, `bool`, `error`, etc.

```go
func processaNome(nome string) (string, int, bool) {
    nomeMaiusculo := strings.ToUpper(nome)
    tamanho := len(nome)
    contemGo := strings.Contains(nome, "Go")
    return nomeMaiusculo, tamanho, contemGo
}
```

## 4\. O "Go Way": Ignorando Retornos com o Identificador Vazio `_`

E se você chamar a função `operacoes`, mas só estiver interessado na soma e na multiplicação? O compilador de Go dará um erro de "variável declarada mas não utilizada" se você capturar `sub` e `div` e não as usar.

A solução idiomática é usar o **identificador vazio `_` (underline)** para explicitamente dizer ao compilador para descartar um valor retornado.

```go
func main() {
	// Só nos importamos com o primeiro e o quarto valor retornado.
	// Os outros dois são descartados.
	soma, _, _, mult := operacoes(10, 5)

	fmt.Printf("Soma: %d, Multiplicação: %d\n", soma, mult)
}
```

**Saída:**

```
Soma: 15, Multiplicação: 50
```

Este é um padrão extremamente comum em Go, especialmente ao lidar com o retorno `(valor, erro)` quando você tem certeza de que a operação não falhará.
