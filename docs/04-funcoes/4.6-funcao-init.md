# **4.6: A Função Especial `init` - Inicialização de Pacotes**

Nesta aula, exploramos uma função especial em Go que não se comporta como as outras que vimos até agora: a função `init`. Ela desempenha um papel fundamental no processo de inicialização de um pacote, permitindo a execução de código de setup antes que qualquer outra parte do pacote seja utilizada.

## 1\. O Que é a Função `init`?

A função `init` é uma função especial que é **invocada automaticamente pelo runtime do Go** quando um pacote é inicializado. Você não a chama explicitamente; o próprio sistema se encarrega de executá-la.

Seu propósito, como o nome sugere, é realizar tarefas de **inicialização** necessárias para que o pacote funcione corretamente, como configurar variáveis, estabelecer conexões, ou registrar componentes.

## 2\. Características Fundamentais da Função `init`

1.  **Execução Automática:** Você nunca chama `init()` no seu código. O runtime do Go a executa por você.
2.  **Execução Antes de `main`:** Em um programa executável, **todas** as funções `init` são garantidas de serem executadas **antes** que a função `main` comece.
3.  **Sem Parâmetros ou Retorno:** A função `init` não pode ter parâmetros e não pode retornar nenhum valor. Sua assinatura é sempre `func init()`.
4.  **Múltiplas Declarações:** Um único arquivo (e um único pacote) pode ter múltiplas funções `init`.

## 3\. Exemplo Prático e Ordem de Execução

A aula demonstra perfeitamente o comportamento da `init` em relação à `main`.

```go
package main

import "fmt"

// A função 'init' será executada primeiro, automaticamente.
func init() {
	fmt.Println("Executando a função init...")
}

func main() {
	fmt.Println("Executando a função main...")
}
```

**Saída:**

```
Executando a função init...
Executando a função main...
```

Observe que, mesmo que a chamada para `main` seja o ponto de partida do nosso programa, a `init` tem a precedência na execução.

## 4\. Múltiplas Funções `init` e Sua Ordem

Como a aula mostrou, você pode declarar várias funções `init` no mesmo arquivo.

**Regra de Execução:**

  * **Dentro de um mesmo arquivo,** as funções `init` são executadas na **ordem em que aparecem no código**, de cima para baixo.
  * Se um pacote tiver múltiplos arquivos, as funções `init` de cada arquivo serão executadas. A ordem de execução entre os arquivos é determinada alfabeticamente pelo nome do arquivo.

<!-- end list -->

```go
package main

import "fmt"

func init() {
	fmt.Println("Função init UM")
}

func main() {
	fmt.Println("Função main")
}

// Esta função também será executada antes da main.
func init() {
	fmt.Println("Função init DOIS")
}
```

**Saída:**

```
Função init UM
Função init DOIS
Função main
```

Note como a ordem de declaração foi respeitada, e ambas foram executadas antes da `main`.

## 5\. O "Go Way": Casos de Uso e a Analogia com Construtores

A analogia com **construtores** de classes em linguagens orientadas a objetos (como Java ou C\#) é útil, mas com uma distinção importante:

  * Um **construtor** está ligado à *criação de uma instância de um objeto*. Ele roda toda vez que um `new` é chamado.
  * Uma função **`init`** está ligada à *inicialização de um pacote*. Ela roda apenas **uma vez**, na primeira vez que o pacote é carregado pelo programa.

**Casos de Uso Comuns para `init`:**

1.  **Inicialização de Variáveis Complexas:** Se uma variável no escopo do pacote precisa de uma lógica de inicialização (ler um arquivo, fazer um cálculo), a `init` é o lugar perfeito para isso.
2.  **Registro de "Drivers":** Este é um padrão clássico em Go. Pacotes como os de banco de dados (`database/sql`) ou de formatos de imagem (`image/png`) usam uma função `init` para se registrarem como "provedores" de uma determinada funcionalidade. Ao importar o pacote (ex: `import _ "image/png"`), sua função `init` roda e o programa principal passa a "saber" como decodificar imagens PNG.
3.  **Verificações de Sanidade:** A função `init` pode ser usada para verificar se uma condição essencial para o funcionamento do pacote é atendida. Se não for, ela pode usar `panic` para interromper a execução do programa com uma mensagem de erro clara.

A função `init` é uma ferramenta poderosa para garantir que seu pacote esteja em um estado consistente e pronto para ser usado antes que qualquer outra parte do seu código interaja com ele.
