# **1.8: A Profundidade dos Tipos Numéricos em Go**

Esta aula explora um conceito crucial: Go não tem apenas um tipo `int`, mas uma família de tipos inteiros e de ponto flutuante, cada um com um **tamanho fixo** em memória. Entender isso é a chave para gerenciar recursos de forma eficiente e evitar bugs sutis.

## 1\. Por que Existem Diferentes Tamanhos?

A principal razão é o controle sobre o uso da memória. Cada tipo de dado ocupa um espaço específico (medido em bits).

  * **Bits:** A menor unidade de dados em um computador, podendo ser 0 ou 1.
  * **Tamanho do Tipo:** Um tipo `int8` usa 8 bits de memória, enquanto um `int64` usa 64 bits (8 vezes mais espaço).

Em um programa que manipula milhões de números, escolher o tipo de inteiro correto pode resultar em uma economia de memória massiva, impactando diretamente a performance da aplicação.

## 2\. O Conceito Central: Signed vs. Unsigned

Esta é a distinção mais importante que a aula aborda.

  * **Signed Integers (Assinados - `int`)**:

      * Podem representar tanto números **positivos quanto negativos**.
      * Para isso, eles usam um de seus bits (o "bit de sinal") para indicar se o número é positivo ou negativo. Isso "corta" pela metade o valor máximo positivo que podem armazenar em comparação com seu equivalente *unsigned*.
      * Exemplos: `int8`, `int16`, `int32`, `int64`.

  * **Unsigned Integers (Não Assinados - `uint`)**:

      * Representam **apenas números positivos** (e o zero).
      * Como não precisam de um bit de sinal, todos os bits são usados para representar o valor, permitindo um valor máximo positivo duas vezes maior que o tipo *signed* de mesmo tamanho.
      * Exemplos: `uint8`, `uint16`, `uint32`, `uint64`.

## 3\. Tabela de Tipos Inteiros e Seus Limites

Aqui está uma referência clara dos tipos, seus tamanhos e os intervalos de valores que eles podem armazenar.

| Tipo (Signed) | Tamanho | Intervalo de Valores |
| :--- | :--- | :--- |
| `int8` | 8 bits | -128 a 127 |
| `int16` | 16 bits | -32.768 a 32.767 |
| `int32` | 32 bits | -2.147.483.648 a 2.147.483.647 |
| `int64` | 64 bits | -9.223.372.036.854.775.808 a 9.223.372.036.854.775.807 |

| Tipo (Unsigned) | Tamanho | Intervalo de Valores |
| :--- | :--- | :--- |
| `uint8` (alias: `byte`) | 8 bits | 0 a 255 |
| `uint16` | 16 bits | 0 a 65.535 |
| `uint32` | 32 bits | 0 a 4.294.967.295 |
| `uint64` | 64 bits | 0 a 18.446.744.073.709.551.615 |

> **Nota do Especialista:** O `uint8` tem um "apelido" (`alias`) muito comum em Go: `byte`. Eles são, na prática, intercambiáveis e representam a mesma coisa.

## 4\. O Overflow: Estourando a Capacidade do Tipo

Como a aula demonstrou perfeitamente, o compilador Go te protege de um erro comum chamado **overflow**. Isso acontece quando você tenta atribuir a uma variável um valor que está fora do intervalo permitido para o seu tipo.

**Exemplos da Aula, Analisados:**

```go
// Exemplo 1: Tentando colocar um número negativo em um uint8
var numero1 uint8
numero1 = -1 // ERRO DE COMPILAÇÃO: constant -1 overflows uint8
```

  * **Motivo:** `uint8` só aceita valores de 0 a 255. `-1` está fora desse intervalo.

<!-- end list -->

```go
// Exemplo 2: Usando um int8 para negativos
var numero2 int8
numero2 = -1 // Válido! -1 está dentro do intervalo de -128 a 127.
```

```go
// Exemplo 3: Estourando o limite positivo do int8
var numero3 int8
numero3 = 128 // ERRO DE COMPILAÇÃO: constant 128 overflows int8
```

  * **Motivo:** O valor máximo para um `int8` é **127**. `128` já é grande demais.

## 5\. Os Tipos Genéricos: `int` e `uint`

E quanto ao tipo `int` que vínhamos usando até agora?

  * Os tipos `int` e `uint` são especiais. Seu tamanho **depende da arquitetura do seu computador**.
      * Em um sistema de **32-bit**, `int` é o mesmo que `int32`.
      * Em um sistema de **64-bit** (a grande maioria dos computadores modernos), `int` é o mesmo que `int64`.
  * Isso garante que o tipo `int` seja sempre o tamanho mais eficiente para a CPU do sistema.

## 6\. O "Go Way": Quando se Preocupar com Isso?

A recomendação da aula está corretíssima e é a prática padrão na comunidade Go:

1.  **Para uso geral, sempre prefira `int`:** Para contadores, índices de loop, e a maioria das variáveis numéricas do dia a dia, use `int`. Ele é grande o suficiente para não causar problemas de overflow e é otimizado para a sua máquina. Não se preocupe em economizar alguns bytes a menos que seja realmente necessário.
2.  **Use tipos específicos (`int32`, `uint8`, etc.) quando você tiver um motivo claro:**
      * **Estruturas de dados massivas:** Se você tem um slice com bilhões de números que você sabe que nunca passarão de 200, usar `uint8` em vez de `int` economizará gigabytes de RAM.
      * **Interoperabilidade:** Ao se comunicar com sistemas externos (APIs, bancos de dados, comunicação de rede, arquivos binários) que exigem um formato de dados com tamanho específico.
      * **Representação de dados:** `uint8` (`byte`) é o tipo natural para representar dados brutos, como o conteúdo de um arquivo ou o corpo de uma requisição HTTP.
