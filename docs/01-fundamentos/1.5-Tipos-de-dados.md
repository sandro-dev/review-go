# **1.5: Tipos de Dados em Go - Tipagem estática e Valores Primitivos**

Esta aula aprofunda o conhecimento sobre variáveis, focando no sistema de tipos de Go. Os conceitos centrais são a **tipagem estática**, os **tipos de dados primitivos** e o comportamento de **inicialização automática** (valores zero).

## 11.gem Estática: A Regra Fundamental

Go é uma linguagem de **tipagem estática**. Isso significa que, uma vez que uma variável é declarada com um tipo específico, esse tipo é fixo e não pode ser alterado durante todo o ciclo de vida da variável.

  * **O que você PODE fazer:** Mudar o **valor** de uma variável, desde que o novo valor seja do mesmo tipo.
  * **O que você NÃO PODE fazer:** Atribuir um valor de um tipo diferente à variável.

**Exemplo Prático:**

```go
package main

import "fmt"

func main() {
	// A variável 'texto' é inferida como do tipo 'string'.
	texto := "valor inicial"
	fmt.Println("Valor original:", texto)

	// CORRETO: Atribuir um novo valor do tipo 'string'.
	texto = "valor modificado"
	fmt.Println("Novo valor:", texto)

	// INCORRETO: Tentar atribuir um valor do tipo 'int'.
	// A linha abaixo causaria um erro de compilação se fosse descomentada.
	// texto = 10 // Erro: cannot use 10 (untyped int constant) as string value in assignment

}
```

## 21.m de Declaração é Importante

Como em a maioria das linguagens compiladas, você deve declarar uma variável antes de poder usá-la. Tentar atribuir um valor ou ler de uma variável que ainda não foi declarada resultará em um erro de compilação, pois o compilador não sabe a que "nome" você está se referindo.

```go
// Erro: 'nome' não foi definido (undefined: nome)
nome = "Alice" 
var nome string 
```

## 31.s Primitivos vs. Tipos Compostos

A aula introduz uma distinção importante:

  * **Tipos Primitivos:** São os blocos de construção fundamentais da linguagem. Eles representam dados simples e indivisíveis. Os principais são:

      * Números (inteiros e ponto flutuante)
      * Strings (texto)
      * Booleanos (verdadeiro/falso)

  * **Tipos Compostos:** São tipos mais complexos, construídos a partir dos tipos primitivos (ou outros tipos compostos). Eles permitem agrupar dados de forma estruturada. Veremos em detalhes mais tarde, mas exemplos incluem:

      * `structs` (para criar tipos customizados, como `Pessoa`)
      * `arrays` e `slices` (para listas de dados)
      * `maps` (para dicionários chave-valor)

## 41.lhando os Tipos Primitivos

### 1.ngs (`string`)

Representam sequências de caracteres (texto). Em Go, literais de string são definidos com aspas duplas `""`.

```go
nome := "Ada Lovelace"
```

> **Nota do Especialista:** Strings em Go são imutáveis e codificadas em UTF-8 por padrão. Isso as torna muito eficientes e robustas para lidar com textos em qualquer idioma.

### 1.ros Inteiros (`int`)

Representam números inteiros (sem casas decimais). Go oferece várias precisões: `int8`, `int16`, `int32`, `int64` e suas versões sem sinal `uint...`. O tipo `int` genérico tem um tamanho que depende da arquitetura do sistema (32 ou 64 bits).

```go
idade := 42
```

### 1.ros de Ponto Flutuante (`float32`, `float64`)

Representam números com casas decimais. `float64` é o mais comum e oferece maior precisão.

```go
alturaEmMetros := 1.75
```

### 1.eanos (`bool`)

Representam valores lógicos e só podem conter `true` (verdadeiro) ou `false` (falso). São a base para o controle de fluxo (condicionais e laços).

```go
eMaiorDeIdade := true
```

## 51.nceito de Valor Zero (Revisitado com Exemplos)

Este é um dos tópicos mais importantes da aula. Como vimos anteriormente, Go garante que nenhuma variável exista em um estado "indefinido". Se você declara uma variável sem atribuir um valor inicial, Go a inicializa automaticamente com o **valor zero** do seu tipo.

A aula demonstrou isso de forma prática:

```go
package main

import "fmt"

func main() {
	// Declarando variáveis sem atribuir valores
	var texto string
	var numero int
	var metro float64 // Usando float64 que é mais comum
	var eFeminino bool

	// Imprimindo seus valores iniciais (zero)
	fmt.Printf("string: '%s'\n", texto) // Usando %q para mostrar que a string é vazia
	fmt.Printf("int: %d\n", numero)
	fmt.Printf("float64: %f\n", metro)
	fmt.Printf("bool: %t\n", eFeminino)
}
```

**Saída:**

```
string: ''
int: 0
float64: 0.000000
bool: false
```

**Tabela de Referência Rápida - Valores Zero:**
| Tipo | Valor Zero | Descrição |
|:---|:---|:---|
| `string` | `""` | String vazia |
| `int`, `float32`, `float64` | `0` | O número zero |
| `bool` | `false` | Falso |

**Ponto de Atenção:** A inicialização automática é uma feature de segurança, mas como a aula alerta, pode levar a bugs lógicos se você não estiver ciente. Se seu código espera que uma variável tenha um valor específico (ex: `idade = 25`) mas ela nunca foi atribuída, ela conterá `0`, o que pode levar a um comportamento inesperado no seu programa.
