# **1.7: Constantes em Go - Valores Imutáveis**

Nesta aula, o foco é em **constantes**, um conceito similar a variáveis, mas com uma diferença crucial: seu valor, uma vez definido, não pode ser alterado.

## 1\. O Conceito: Variável vs. Constante

  * **Variável:** Um espaço na memória cujo valor **pode mudar** durante a execução do programa. Usa-se a palavra-chave `var` ou o operador `:=`.
  * **Constante:** Um identificador para um valor **fixo e imutável**. Uma vez declarado, seu valor não pode ser reatribuído. Usa-se a palavra-chave `const`.

## 2\. Por que e Quando Usar Constantes?

A aula levanta uma excelente questão: por que usar uma constante se eu posso simplesmente usar uma variável e não alterá-la? A resposta está em três pilares da boa engenharia de software:

1.  **Segurança e Prevenção de Bugs:** Como demonstrado, o compilador Go proíbe ativamente qualquer tentativa de alterar o valor de uma constante. Isso garante que valores críticos, que não devem mudar (como uma taxa de juros, o valor de PI, um status de configuração), não sejam modificados acidentalmente em outra parte do código.

2.  **Legibilidade e Manutenibilidade:** Constantes dão um nome significativo a "números mágicos" ou "strings mágicas".

      * **Ruim (número mágico):** `if status == 2 { ... }`
      * **Bom (usando constante):** `const StatusAprovado = 2` ... `if status == StatusAprovado { ... }`

    O segundo exemplo é muito mais claro. Se o valor de `StatusAprovado` precisar mudar no futuro, você só o altera em um lugar: na declaração da constante.

3.  **Performance:** O compilador sabe que o valor de uma constante é fixo. Isso permite que ele faça otimizações, substituindo o nome da constante pelo seu valor real diretamente no código compilado.

## 3\. Sintaxe e Declaração

A declaração de uma constante é simples e se parece com a declaração de uma variável com `var`, mas usando `const`.

  * **Palavra-chave:** `const`
  * **Atribuição:** O valor deve ser atribuído na mesma linha da declaração.
  * **Operador:** **Não se usa** o operador de declaração curta `:=` para constantes.

**Exemplo Prático (demonstrando a imutabilidade):**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	// Declara uma constante 'Taxa'.
	// O tipo é inferido pelo compilador (neste caso, int).
	const Taxa = 10

	fmt.Println("Valor da constante:", Taxa)
	fmt.Println("Tipo da constante:", reflect.TypeOf(Taxa))

	// A linha abaixo, se descomentada, causará um erro de compilação.
	// Taxa = 5 // Erro: cannot assign to Taxa (constant 10 of type int)
}
```

**Saída:**

```
Valor da constante: 10
Tipo da constante: int
```

O compilador age como um guardião, garantindo a regra da imutabilidade.

## 4\. Constantes Tipadas e "Não Tipadas" (Untyped)

Este é um conceito mais avançado, mas muito poderoso em Go.

  * **Constante Não Tipada (Untyped):** Quando você declara `const Pi = 3.14`, `Pi` não é rigidamente um `float64` ou `float32`. É uma constante de alta precisão que pode ser usada de forma flexível com qualquer tipo numérico compatível.

  * **Constante Tipada (Typed):** Você pode explicitamente definir o tipo da constante: `const SegundoEmNano int64 = 1000000000`. Agora, esta constante é estritamente do tipo `int64`.

**Por que isso é útil?** Constantes não tipadas oferecem grande flexibilidade.

```go
package main

import "fmt"

func main() {
	const Limite = 100 // Constante 'Limite' é NÃO TIPADA (untyped int)

	var limite8 int8 = Limite     // Válido! 100 cabe em um int8
	var limite32 int32 = Limite   // Válido!
	var limite64 int64 = Limite   // Válido!

	fmt.Println(limite8, limite32, limite64)

	const LimiteTyped int = 100 // Constante 'LimiteTyped' é TIPADA (typed int)
	
	// A linha abaixo daria erro, pois são tipos diferentes (int vs int8)
	// var outroLimite8 int8 = LimiteTyped 
}
```

## 5\. Boas Práticas (O "Go Way")

  * Use constantes para qualquer valor em seu programa que seja fixo e não deva mudar durante a execução.
  * Dê nomes claros e descritivos às suas constantes.
  * Se a constante precisa ser usada por outros pacotes, comece seu nome com uma letra maiúscula (ex: `const TaxaSelic = 0.12`). Se for para uso interno apenas no pacote atual, comece com letra minúscula (ex: `const maxRetentativas = 3`).
