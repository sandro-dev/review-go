# **1.6: Operadores em Go - Aritmética e Concatenação**

Nesta aula, exploramos os operadores, que são os símbolos que nos permitem executar operações em nossas variáveis e valores. Nenhum programa útil pode ser construído sem eles. Focaremos nos operadores aritméticos básicos e no operador de concatenação de strings.

## 11.adores Aritméticos

Estes são os operadores que você provavelmente já conhece da matemática. Eles são usados para realizar cálculos com tipos numéricos (`int`, `float64`, etc.).

| Operador | Nome | Exemplo | Resultado |
| :--- | :--- | :--- | :--- |
| `+` | Adição | `10 + 20` | `30` |
| `-` | Subtração | `20 - 10` | `10` |
| `*` | Multiplicação | `10 * 20` | `200` |
| `/` | Divisão | `20 / 10` | `2` |
| `%` | Módulo (Resto da Divisão)| `10 % 3` | `1` |

**Exemplo Prático:**

```go
package main

import "fmt"

func main() {
	num1 := 10
	num2 := 20

	// A operação pode ser feita diretamente na função de impressão...
	fmt.Println("Soma direta:", num1 + num2)

	// ...ou, de forma mais comum, armazenando o resultado em uma nova variável.
	resultado := num1 + num2
	fmt.Println("Resultado (soma):", resultado)

	resultado = num1 * num2
	fmt.Println("Resultado (multiplicação):", resultado)
}
```

## 21.o de Atenção: A Divisão de Inteiros

A aula destacou um comportamento crucial e que frequentemente confunde iniciantes: **a divisão entre dois números inteiros em Go sempre resultará em um número inteiro.** A parte decimal é simplesmente descartada (truncada).

```go
num1 := 10
num2 := 20

resultado := num1 / num2 // 10 dividido por 20 é 0.5. A parte decimal é removida.
fmt.Println(resultado)   // Saída: 0
```

Para obter um resultado com casas decimais, pelo menos um dos números na operação deve ser do tipo ponto flutuante (`float`).

```go
num3 := 10.0 // Este agora é um float64
num4 := 20.0 // Este também

resultadoFloat := num3 / num4
fmt.Println(resultadoFloat) // Saída: 0.5
```

Quando você realiza uma operação aritmética com diferentes tipos numéricos (ex: `int` e `float64`), Go exige que você faça a conversão de tipo explicitamente para evitar perda de dados acidental. O operador `:=` infere o tipo da variável de resultado com base nos tipos dos operandos.

## 31.erador de Concatenação de Strings

O operador `+`, quando usado com strings, não realiza uma soma matemática. Em vez disso, ele executa uma **concatenação**, que é a junção de duas ou mais strings para formar uma nova.

```go
package main

import "fmt"

func main() {
	texto1 := "Olá, "
	texto2 := "Mundo!"

	saudacao := texto1 + texto2
	fmt.Println(saudacao)
}
```

**Saída:**

```
Olá, Mundo!
```

## 41.amenta Avançada: Verificando o Tipo em Tempo de Execução com `reflect`

A aula introduziu uma ferramenta poderosa para depuração e metaprogramação: o pacote `reflect`. Ele permite que você inspecione o tipo de uma variável enquanto o programa está em execução.

**a) Importando Múltiplos Pacotes:**
Para importar mais de um pacote, usamos a sintaxe de bloco com parênteses, que é a forma idiomática em Go.

```go
import (
	"fmt"
	"reflect"
)
```

**b) Usando `reflect.TypeOf()`:**
A função `TypeOf()` do pacote `reflect` recebe uma variável e retorna seu tipo.

**Exemplo Completo:**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	// Operação com floats
	num1 := 10.0
	num2 := 20.0
	resultadoFloat := num1 / num2

	// Operação com strings
	texto1 := "Go"
	texto2 := "lang"
	resultadoString := texto1 + texto2

	fmt.Println("Valor float:", resultadoFloat)
	fmt.Println("Tipo da variável 'resultadoFloat':", reflect.TypeOf(resultadoFloat))

	fmt.Println("---------------------------------")
	
	fmt.Println("Valor string:", resultadoString)
	fmt.Println("Tipo da variável 'resultadoString':", reflect.TypeOf(resultadoString))
}
```

**Saída:**

```
Valor float: 0.5
Tipo da variável 'resultadoFloat': float64
---------------------------------
Valor string: Golang
Tipo da variável 'resultadoString': string
```

> **Nota do Especialista:** O pacote `reflect` é extremamente poderoso, mas também tem um custo de performance e pode tornar o código mais complexo e menos seguro em termos de tipagem. Para o aprendizado e depuração, é uma ótima ferramenta. Em código de produção, seu uso deve ser criterioso e justificado, pois ele contorna as verificações de tipo feitas pelo compilador.
