# **1.4: Variáveis em Go - Declaração, Atribuição e Tipagem**

Esta aula introduz o conceito de variáveis em Go, que são a forma fundamental de armazenar e manipular dados em um programa. Abordaremos as diferentes maneiras de declarar variáveis, a importância dos tipos e as regras que o compilador impõe.

## 1\. O que é uma Variável?

Uma variável é um espaço na memória, identificado por um nome, que armazena um valor. Este valor pode ser modificado durante a execução do programa. Elas são essenciais para realizar operações, como os exemplos citados na aula: armazenar um peso para conversão, guardar o nome de um usuário, etc.

## 2\. A Declaração Explícita com `var`

A forma mais explícita e fundamental de se declarar uma variável em Go é usando a palavra-chave reservada `var`. A sintaxe é:

`var <nome_da_variavel> <tipo>`

  * **`var`:** A palavra-chave que inicia a declaração.
  * **`nome_da_variavel`:** O nome que você dará à variável (ex: `peso`, `nome`, `idade`).
  * **`tipo`:** O tipo de dado que a variável pode armazenar (ex: `int`, `string`, `bool`).

**Exemplo:**

```go
package main

import "fmt"

func main() {
	// Declara uma variável chamada 'peso' que só pode armazenar números inteiros.
	var peso int

	// Imprime o valor da variável 'peso'.
	fmt.Println(peso) 
}
```

**Saída:**

```
0
```

## 3\. O Conceito de Valor Zero (Zero Value)

Como visto no exemplo acima, quando imprimimos a variável `peso` sem ter atribuído um valor a ela, o resultado foi `0`. Isso demonstra uma característica de segurança muito importante em Go: **não existem variáveis não inicializadas**.

Toda variável declarada em Go é automaticamente inicializada com um "valor zero" correspondente ao seu tipo. Isso evita uma categoria inteira de bugs comuns em outras linguagens, onde uma variável pode conter "lixo" de memória.

**Valores Zero Comuns:**
| Tipo | Valor Zero |
| :--- | :--- |
| `int` (e variantes como `int32`, `int64`) | `0` |
| `float64` (e `float32`) | `0.0` |
| `string` | `""` (uma string vazia) |
| `bool` | `false` |
| Ponteiros, slices, maps, channels, interfaces | `nil` |

## 4\. Atribuição de Valores com `=`

Após uma variável ser declarada, você pode atribuir um valor a ela usando o operador de atribuição `=`.

```go
package main

import "fmt"

func main() {
	// 1. Declaração
	var mensagem string

	// 2. Atribuição
	mensagem = "Olá, Mundo!"

	fmt.Println(mensagem)
}
```

Go é uma linguagem **estaticamente tipada**. Isso significa que, uma vez que `mensagem` foi declarada como `string`, você só pode atribuir valores do tipo string a ela. Tentar atribuir um número resultará em um erro de compilação:

```go
var peso int
peso = "dez" // Erro! cannot use "dez" (type string) as type int in assignment
```

## 5\. A Forma Idiomática: Operador de Declaração Curta `:=`

A aula apresenta uma forma mais concisa e comum de se trabalhar com variáveis dentro de funções: o **operador de declaração curta** `:=`.

Este operador realiza três ações em um único passo:

1.  **Declara** a variável.
2.  **Infere** o tipo da variável com base no valor à direita.
3.  **Atribui** o valor à variável.

**Exemplo:**

```go
package main

import "fmt"

func main() {
	// Declara, infere o tipo (int) e atribui o valor 10 à variável 'idade'.
	idade := 10 

	// Declara, infere o tipo (string) e atribui o valor "Go" à variável 'linguagem'.
	linguagem := "Go"

	// Declara, infere o tipo (float64) e atribui o valor 10.5 à variável 'versao'.
	versao := 10.5

	fmt.Println(idade)
	fmt.Println(linguagem)
	fmt.Println(versao)
}
```

  * **Inferência de Tipo:** Go analisa o valor (`30`, `"Go"`, `10.5`) e automaticamente define o tipo da variável. Você não precisa escrever `int`, `string` ou `float64`.
  * **Regra Importante:** O operador `:=` só pode ser usado **dentro de funções**. Para declarar variáveis no escopo do pacote (fora de qualquer função), você deve usar a palavra-chave `var`.

## 6\. O "Go Way": Sem Variáveis Inutilizadas

Como bem destacado na aula, o compilador Go é muito rigoroso. Ele gerará um erro se você declarar uma variável e não a utilizar em nenhum lugar do seu código.

**`peso declared and not used`**

  * **Por quê?** Isso força o desenvolvedor a manter o código limpo e legível. Uma variável não utilizada pode ser um sinal de código "morto" ou de um bug onde o desenvolvedor esqueceu de usar a variável que criou.

## 7\. Regra de Nomenclatura: Palavras Reservadas

Você não pode nomear uma variável com uma das **palavras reservadas** da linguagem. Essas palavras têm um significado especial para o compilador.

  * **Exemplos de Palavras Reservadas:** `var`, `func`, `import`, `package`, `if`, `for`, `return`, `type`, etc.

Tentar usar um nome como `var func int` resultará em um erro de sintaxe, pois o compilador não consegue interpretar a instrução.

> **Nota do Especialista:** A simplicidade do Go é refletida no número de palavras reservadas. Go tem apenas **25 palavras reservadas**. Em comparação, C\# tem mais de 100 e Java tem cerca de 50. Isso torna a sintaxe fundamental da linguagem muito mais fácil de aprender e dominar.

**Resumo da Aula:**

| Forma de Declaração | Sintaxe | Escopo | Uso Principal |
| :--- | :--- | :--- | :--- |
| **Declaração Explícita** | `var nome tipo` | Dentro e fora de funções | Declarar variáveis de pacote ou quando se quer iniciar com o valor zero. |
| **Declaração Curta** | `nome := valor` | Apenas dentro de funções | É a forma preferida e mais comum para declarar e inicializar variáveis locais. |
