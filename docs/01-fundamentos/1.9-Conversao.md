# **1.9: Conversão de Tipos (Type Casting & Parsing)**

Esta aula aborda uma tarefa essencial na programação: a conversão de um valor de um tipo de dado para outro. Exploramos duas abordagens principais: a **conversão direta** entre tipos numéricos e o **parsing** de strings usando o poderoso pacote `strconv`.

## 1\. Introdução: Por que Converter Tipos?

A conversão de tipos é necessária constantemente. Os principais motivos são:

  * **Interoperabilidade:** Sistemas diferentes podem enviar dados em formatos diferentes (ex: uma API que envia todos os números como strings em um JSON).
  * **Entrada do Usuário:** Dados provenientes de formulários web ou linhas de comando são quase sempre recebidos como texto (strings) e precisam ser convertidos para números ou outros tipos para serem processados.
  * **Cálculos:** Para realizar operações aritméticas, os tipos precisam ser compatíveis. Não se pode somar um `int8` com um `int64` diretamente.

## 2\. Conversão Numérica Explícita (Casting)

Go exige que a conversão entre tipos numéricos seja **explícita**. Você não pode simplesmente atribuir uma variável de um tipo a outra, mesmo que os valores sejam compatíveis. A sintaxe para isso é `T(v)`, onde `T` é o tipo para o qual você quer converter e `v` é o valor.

**Exemplo 1: Convertendo um tipo menor para um maior (Seguro)**

```go
package main

import "fmt"

func main() {
	var numeroInt8 int8 = 127
	
	// A linha abaixo causaria um erro de compilação:
	// var numeroInt int = numeroInt8 // Erro: cannot use numeroInt8 (variable of type int8) as int value in assignment

	// A forma CORRETA é a conversão explícita:
	var numeroInt int = int(numeroInt8)

	fmt.Println("Valor convertido para int:", numeroInt)
}
```

**Exemplo 2: Convertendo um tipo maior para um menor**
Isso é possível, mas você deve ter certeza de que o valor do tipo maior "cabe" no tipo menor para evitar overflow.

```go
var numeroInt int = 100
var numeroInt8 int8 = int8(numeroInt) // Válido, pois 100 está no range de int8
```

## 3\. Ponto de Atenção: Perda de Precisão

A conversão de um número de ponto flutuante (`float`) para um inteiro (`int`) é uma operação com **perda de dados**. Como visto na aula, a parte decimal é simplesmente **truncada** (cortada), não arredondada.

```go
package main

import "fmt"

func main() {
	var numeroFloat float64 = 127.8
	var numeroInt int = int(numeroFloat)

	fmt.Println("Original (float64):", numeroFloat) // Saída: 127.8
	fmt.Println("Convertido (int):", numeroInt)   // Saída: 127
}
```

## 4\. A Forma Robusta: Conversão de Strings com `strconv`

Para converter strings em outros tipos (e vice-versa), não usamos casting. A maneira correta e segura em Go é usar o pacote da biblioteca padrão `strconv` (string conversion).

> **Documentação Oficial:** [pkg.go.dev/strconv](https://pkg.go.dev/strconv)

Este pacote oferece funções especializadas como `ParseBool`, `ParseInt`, `ParseFloat`, etc.

## 5\. Desempacotando `strconv`: O Padrão "Valor, Erro"

Uma das características mais idiomáticas de Go é introduzida aqui: **funções que podem falhar retornam múltiplos valores**, geralmente `(resultado, erro)`.

A lógica é a seguinte:

1.  A função tenta realizar a conversão.
2.  Se for bem-sucedida, ela retorna o **valor convertido** e um valor de erro **`nil`** (`nil` é o "zero" para erros, significando "sem erro").
3.  Se falhar (ex: tentar converter `"abc"` para um inteiro), ela retorna um **valor zero** para o tipo de resultado e um **objeto de erro** descrevendo o que deu errado.

## 6\. Lidando com Erros (A Primeira Visão): O Identificador Vazio `_`

O compilador Go exige que todas as variáveis declaradas sejam usadas. Como, por enquanto, não vamos tratar o erro retornado pelas funções `strconv`, usamos o **identificador vazio `_` (underline)** para explicitamente dizer ao compilador: "Eu sei que esta função retorna um segundo valor, mas eu escolho ignorá-lo".

```go
// A variável 'b' recebe o primeiro valor retornado (o booleano).
// O '_' recebe o segundo valor (o erro) e o descarta.
b, _ := strconv.ParseBool("true") 
```

**Atenção:** Este é um atalho para o aprendizado. Em código de produção, você **quase sempre** deve verificar o erro para tornar seu programa robusto\! Veremos isso em detalhes mais adiante.

## 7\. Explorando as Funções `strconv` (Exemplos Práticos)

```go
package main

import (
	"fmt"
	"reflect"
	"strconv"
)

func main() {
	// --- ParseBool ---
	// Converte uma string para booleano. Aceita "1", "t", "T", "true", "TRUE", "True", etc.
	valorBool, _ := strconv.ParseBool("true")
	fmt.Printf("Valor: %v, Tipo: %T\n", valorBool, valorBool)
	
	// --- ParseInt ---
	// Sintaxe: ParseInt(string, base, bitSize)
	// base: 10 para decimal, 2 para binário, 16 para hexadecimal, etc.
	// bitSize: 0, 8, 16, 32, ou 64 (para int, int8, int16, etc.)
	valorInt, _ := strconv.ParseInt("-42", 10, 64)
	fmt.Printf("Valor: %v, Tipo: %T\n", valorInt, valorInt)

	// --- ParseFloat ---
	// Sintaxe: ParseFloat(string, bitSize)
	// bitSize: 32 ou 64 (para float32 ou float64)
	textoFloat := "42.55"
	valorFloat, _ := strconv.ParseFloat(textoFloat, 64)
	fmt.Printf("Valor: %v, Tipo: %T\n", valorFloat, valorFloat)
	
	// --- Exemplo de ERRO ---
	// Tentando converter um float em formato de string para um inteiro
	_, err := strconv.ParseInt(textoFloat, 10, 64)
	if err != nil {
		// Pela primeira vez, vamos inspecionar o erro!
		fmt.Println("--- Exemplo de Erro ---")
		fmt.Printf("Erro ao tentar converter '%s' para int: %v\n", textoFloat, err)
	}
}
```

**Saída:**

```
Valor: true, Tipo: bool
Valor: -42, Tipo: int64
Valor: 42.55, Tipo: float64
--- Exemplo de Erro ---
Erro ao tentar converter '42.55' para int: strconv.ParseInt: parsing "42.55": invalid syntax
```

## 8\. Bônus: Ferramentas e Conceitos Adicionais Introduzidos

  * **`fmt.Printf` e Verbos de Formatação:** Uma alternativa ao `Println` que permite formatar a string de saída.
      * `%v`: Imprime o valor em um formato padrão.
      * `%T`: Imprime o **Tipo** da variável.
      * `\n`: Caractere de "nova linha".
  * **Auto-Import:** O Go Playground (e editores de código modernos como o VS Code) detecta quando você usa um pacote que não foi importado (como `strconv`) e o adiciona automaticamente à cláusula `import`.
