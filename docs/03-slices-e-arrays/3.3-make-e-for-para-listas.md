# **3.3: Manipulação Dinâmica de Slices e Iteração**

Até agora, trabalhamos com slices "estáticos" — criados com um conjunto fixo de valores. No entanto, a verdadeira força dos slices em Go está em sua natureza **dinâmica**. Nesta aula, vamos aprender a adicionar elementos a um slice, criá-los com um tamanho pré-definido e, o mais importante, iterar sobre seus elementos com um laço `for` para processar os dados.

## 1\. Adicionando Elementos com a Função `append`

Na maioria das aplicações, as coleções de dados crescem e mudam. A principal ferramenta para adicionar novos elementos a um slice em Go é a função nativa `append`.

**Sintaxe:** `slice = append(slice_original, elemento1, elemento2, ...)`

  * **`append`:** A função que adiciona elementos.
  * **`slice_original`:** O primeiro argumento é sempre o slice ao qual você quer adicionar.
  * **`elemento(s)`:** Os valores que você deseja adicionar ao final do slice.

**Ponto Crucial (O "Go Way"):** A função `append` **retorna um novo slice**. Você **deve** reatribuir o resultado de volta à variável original (`lista = append(...)`). Isso é necessário porque, se o slice não tiver capacidade suficiente, o Go alocará um novo array subjacente maior e retornará um slice apontando para ele.

**Exemplo Prático (int e string):**

```go
package main

import "fmt"

func main() {
	// --- Exemplo com Inteiros ---
	lista := []int{4, 9, 6, 7}
	fmt.Println("Lista original:", lista, "Tamanho:", len(lista))

	// Adicionando o número 8 ao final da lista
	lista = append(lista, 8)

	fmt.Println("Lista após append:", lista, "Tamanho:", len(lista))
	fmt.Println("--------------------")

	// --- Exemplo com Strings ---
	listaDeStrings := []string{"Go", "C#", "Java"}
	fmt.Println("Strings originais:", listaDeStrings)

	listaDeStrings = append(listaDeStrings, "Ruby")

	fmt.Println("Strings após append:", listaDeStrings)
}
```

**Saída:**

```
Lista original: [4 9 6 7] Tamanho: 4
Lista após append: [4 9 6 7 8] Tamanho: 5
--------------------
Strings originais: [Go C# Java]
Strings após append: [Go C# Java Ruby]
```

## 2\. Criando Slices com Tamanho Definido: A Função `make`

E se você não tiver os valores iniciais, mas souber de antemão quantos elementos seu slice precisará ter? Usar a função `make` é a forma mais eficiente de fazer isso.

**Sintaxe:** `make([]Tipo, tamanho)`

  * **`make`:** A função para alocar e inicializar slices, maps e channels.
  * **`[]Tipo`:** O tipo do slice a ser criado.
  * **`tamanho`:** O número de elementos que o slice terá inicialmente.

**Importante:** `make` não apenas aloca o espaço, mas também inicializa cada uma das posições com o **valor zero** do tipo especificado.

```go
package main

import "fmt"

func main() {
	// Cria um slice de inteiros com tamanho 1.
	// A posição 0 é inicializada com o valor zero de int, que é 0.
	lista := make([]int, 1)
	fmt.Println("Lista criada com make:", lista) // Saída: [0]

	// Agora podemos atribuir um valor a essa posição existente
	lista[0] = 5
	fmt.Println("Após atribuição:", lista) // Saída: [5]

	// E continuar adicionando novos elementos com append
	lista = append(lista, 2)
	lista = append(lista, 3)
	fmt.Println("Após appends:", lista) // Saída: [5 2 3]
}
```

## 3\. O Padrão Essencial: Iterando sobre Slices com `for`

Quase sempre que você tem uma coleção de dados, você precisa processá-la item por item. A combinação de um slice com um laço `for` clássico é um dos padrões mais fundamentais em Go.

Usamos `len(lista)` para definir a condição de parada do laço e a variável do laço (`i`) como o índice para acessar cada elemento.

```go
lista := []int{5, 2, 3}

// O laço vai de i = 0 até i < 3 (ou seja, i = 2)
for i := 0; i < len(lista); i++ {
    // Em cada iteração, 'i' representa a posição atual (0, 1, 2)
    // 'lista[i]' acessa o valor naquela posição.
    fmt.Printf("Valor na posição %d é %d\n", i, lista[i])
}
```

**Saída:**

```
Valor na posição 0 é 5
Valor na posição 1 é 2
Valor na posição 2 é 3
```

## 4\. Exercício Prático: Calculando a Média dos Valores

Vamos aplicar tudo o que aprendemos para resolver o problema proposto na aula: calcular a média dos números em um slice.

**Lógica:**

1.  Criar uma variável (`somaTotal`) para acumular a soma de todos os números, iniciando-a em zero.
2.  Usar um laço `for` para percorrer cada elemento do slice.
3.  Dentro do laço, adicionar o valor do elemento atual (`lista[i]`) à `somaTotal`.
4.  Após o término do laço, dividir a `somaTotal` pelo número de elementos (`len(lista)`).

<!-- end list -->

```go
package main

import "fmt"

func main() {
	lista := []int{1, 2, 3}
	somaTotal := 0

	// 1. Loop para somar todos os elementos
	for i := 0; i < len(lista); i++ {
		somaTotal += lista[i] // Acumula a soma
	}

	// 2. Calcula a média
	// Ponto de atenção: A divisão de dois inteiros em Go resulta em um inteiro.
	// Para este exemplo, funciona bem.
	media := somaTotal / len(lista)

	fmt.Println("A lista é:", lista)
	fmt.Println("A soma total é:", somaTotal)
	fmt.Println("A média é:", media)
}
```

**Saída:**

```
A lista é: [1 2 3]
A soma total é: 6
A média é: 2
```

> **Nota do Especialista:** Cuidado com a divisão de inteiros\! Se a lista fosse `[]int{1, 2, 4}`, a soma seria `7`. A operação `7 / 3` em Go resultaria em `2` (a parte decimal é truncada). Para obter uma média precisa (2.33...), você precisaria converter os números para `float64` antes da divisão: `mediaPrecisa := float64(somaTotal) / float64(len(lista))`.
