# **3.4: Filtragem de Slices - Criando Sub-listas**

Muitas vezes, ao trabalhar com uma grande coleção de dados, nosso objetivo não é usar a lista inteira, mas sim extrair um subconjunto dela que atenda a um critério específico. Este processo é chamado de **filtragem**. A aula demonstra como criar uma "sub-lista" (um novo slice) a partir de uma lista maior.

## 1\. O Problema: Criando uma Lista a Partir de Outra

O cenário proposto é claro e prático:

  * **Lista Fonte:** Temos uma lista de números inteiros: `[2, 10, 9, 4, 1, 8, 3]`.
  * **Objetivo:** Criar uma **nova lista** contendo apenas os números da lista fonte que são **menores que 5**.
  * **Resultado Esperado:** `[2, 4, 1, 3]`

## 2\. A Lógica da Filtragem: Passo a Passo

Para resolver este problema, seguimos uma receita lógica que é um padrão fundamental em programação:

1.  **Definir a Fonte:** Ter a nossa lista original (`listaToda`).
2.  **Preparar o Destino:** Criar uma nova lista, inicialmente vazia, para armazenar os resultados (`listaMenorQue5`).
3.  **Iterar:** Percorrer **cada um** dos elementos da lista fonte.
4.  **Testar (Filtrar):** Para cada elemento, aplicar uma condição (`if`). No nosso caso, "o número é menor que 5?".
5.  **Adicionar:** Se a condição for verdadeira, adicionar o elemento à nossa lista de destino.

## 3\. Implementação em Go

A aula implementa essa lógica usando as ferramentas que já conhecemos.

### a) Passo 1 e 2: Preparando os Slices

```go
package main

import "fmt"

func main() {
	// Passo 1: A lista original (fonte)
	listaToda := []int{2, 10, 9, 4, 1, 8, 3}

	// Passo 2: A lista de destino, criada vazia
	// make([]int, 0) cria um slice de inteiros com tamanho 0.
	// É a maneira perfeita de iniciar um slice que será preenchido dinamicamente.
	listaMenorQue5 := make([]int, 0)

	fmt.Println("Lista original:", listaToda)
	fmt.Println("Lista de destino (inicialmente):", listaMenorQue5)
}
```

### b) Passo 3, 4 e 5: O Laço de Filtragem

```go
// (continuação do código acima)

// Passo 3: Iterar sobre a lista fonte
for i := 0; i < len(listaToda); i++ {
    numeroAtual := listaToda[i]

    // Passo 4: Testar a condição
    if numeroAtual < 5 {
        // Passo 5: Adicionar o número à lista de destino se a condição for verdadeira
        listaMenorQue5 = append(listaMenorQue5, numeroAtual)
        
        // A linha de debug da aula é ótima para visualizar o processo:
        fmt.Printf("Na posição %d, o número %d é < 5. Nova lista: %v\n", i, numeroAtual, listaMenorQue5)
    }
}

fmt.Println("\nResultado final:", listaMenorQue5)
```

## 4\. Visualizando a Execução (Trace)

A melhor forma de entender o processo é seguir o fluxo, como a aula demonstrou com as impressões dentro do laço:

| `i` | `numeroAtual` | Condição `numeroAtual < 5`? | `listaMenorQue5` (após a iteração) |
| :--- | :--- | :--- | :--- |
| 0 | 2 | `true` | `[2]` |
| 1 | 10 | `false` | `[2]` (sem alteração) |
| 2 | 9 | `false` | `[2]` (sem alteração) |
| 3 | 4 | `true` | `[2, 4]` |
| 4 | 1 | `true` | `[2, 4, 1]` |
| 5 | 8 | `false` | `[2, 4, 1]` (sem alteração) |
| 6 | 3 | `true` | `[2, 4, 1, 3]` |

Ao final do laço, a `listaMenorQue5` contém exatamente os elementos que passaram pelo filtro.

## 5\. O "Go Way": Iterando com `for...range`

O laço `for` clássico com índice (`for i := 0; ...`) funciona perfeitamente, mas Go oferece uma sintaxe mais limpa, segura e idiomática para iterar sobre coleções: o **`for...range`**.

**Sintaxe:** `for indice, valor := range nomeDoSlice { ... }`

O `for...range` nos dá diretamente o índice e o valor de cada elemento a cada iteração, tornando o código mais legível e evitando o acesso manual `listaToda[i]`.

**Reescrevendo nosso filtro com `for...range`:**

```go
package main

import "fmt"

func main() {
	listaToda := []int{2, 10, 9, 4, 1, 8, 3}
	listaMenorQue5 := make([]int, 0)

	// Usando for...range. É a forma preferida em Go!
	// '_' ignora o índice, pois só precisamos do valor.
	for _, numero := range listaToda {
		if numero < 5 {
			listaMenorQue5 = append(listaMenorQue5, numero)
		}
	}

	fmt.Println("Resultado final (com for...range):", listaMenorQue5)
}
```

Este código faz exatamente a mesma coisa que o anterior, mas é considerado mais limpo e seguro na comunidade Go. A intenção ("para cada número na lista...") fica muito mais explícita.
