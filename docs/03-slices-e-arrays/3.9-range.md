# **3.9: Iterando sobre Maps com `for...range`**

Assim como precisamos percorrer os itens de um slice, muitas vezes precisamos processar cada par chave-valor dentro de um map. Nesta aula, aprendemos a forma idiomática e correta de fazer isso em Go, utilizando uma variação poderosa do laço `for`: o `for...range`.

## 1\. O Desafio: Por que o `for` Clássico Não Funciona?

Como a aula aponta, a estrutura de laço que usamos para slices (`for i := 0; i < len(lista); i++`) não se aplica a maps por duas razões fundamentais:

1.  **Maps são Não Ordenados:** Não existe um "primeiro" ou "segundo" elemento com um índice `0` ou `1`. A ordem dos elementos é imprevisível.
2.  **Acesso por Chave, Não por Índice:** Acessamos os dados de um map usando uma chave (ex: `"São Paulo"`), não um índice numérico sequencial.

## 2\. A Solução: O `for...range` para Maps

Go oferece uma sintaxe `for...range` especificamente projetada para iterar sobre coleções como slices, arrays, e, claro, maps. Quando usado com um map, ele nos fornece, a cada iteração, o par chave-valor do elemento atual.

**Sintaxe:**
`for chave, valor := range meuMap { ... }`

  * **`chave`, `valor`:** Duas novas variáveis que você declara na hora. A cada volta do laço, Go irá preenchê-las com a chave e o valor do par atual. Você pode dar os nomes que quiser a elas.
  * **`:=`:** O operador de declaração curta, como já conhecemos.
  * **`range meuMap`:** A instrução que diz ao Go para percorrer todos os pares chave-valor contidos em `meuMap`.

## 3\. Exemplo Prático Analisado

Vamos usar o código da aula para ver o `for...range` em ação.

```go
package main

import "fmt"

func main() {
	// Nosso map de exemplo
	populacaoCidades := map[string]int{
		"São Paulo": 10000000,
		"CG":        700000, // Corrigindo o valor para 700 mil, como no exemplo anterior
	}

	fmt.Println("Iterando sobre o map:")

	// A cada iteração, 'cidade' receberá a chave e 'populacao' receberá o valor.
	for cidade, populacao := range populacaoCidades {
		fmt.Printf("Cidade: %s, Habitantes: %d\n", cidade, populacao)
	}
}
```

**Saída Possível:**

```
Iterando sobre o map:
Cidade: São Paulo, Habitantes: 10000000
Cidade: CG, Habitantes: 700000
```

**Ponto Crucial (O "Go Way"):** A ordem em que os itens são impressos **não é garantida**. Em outra execução, a saída poderia ser:

```
Iterando sobre o map:
Cidade: CG, Habitantes: 700000
Cidade: São Paulo, Habitantes: 10000000
```

Nunca dependa da ordem de iteração de um map. Se a ordem for importante, você deve extrair as chaves para um slice, ordenar o slice e então iterar sobre o slice para acessar o map na ordem desejada.

## 4\. Rastreando a Execução do Laço

O processo que o Go executa é simples e poderoso:

1.  **Início do Laço:** Go pega o map `populacaoCidades`.
2.  **Primeira Iteração:**
      * Go seleciona um par chave-valor (ex: `"São Paulo": 10000000`).
      * A variável `cidade` recebe o valor `"São Paulo"`.
      * A variável `populacao` recebe o valor `10000000`.
      * O bloco de código dentro do `for` é executado com esses valores.
3.  **Segunda Iteração:**
      * Go seleciona o próximo par chave-valor disponível (ex: `"CG": 700000`).
      * A variável `cidade` recebe o valor `"CG"`.
      * A variável `populacao` recebe o valor `700000`.
      * O bloco de código é executado novamente com os novos valores.
4.  **Fim do Laço:** Como não há mais pares no map, o laço termina.

## 5\. Variações do `for...range` com Maps

Às vezes, você não precisa da chave e do valor. O `for...range` é flexível.

### a) Apenas as Chaves

Se você fornecer apenas uma variável, o `range` em um map retornará apenas as chaves.

```go
fmt.Println("\nIterando apenas sobre as chaves:")
for cidade := range populacaoCidades {
	fmt.Println("Chave:", cidade)
}
```

### b) Apenas os Valores

Se você só precisa dos valores, pode usar o **identificador vazio `_`** para ignorar a chave.

```go
fmt.Println("\nIterando apenas sobre os valores:")
var populacaoTotal int
for _, populacao := range populacaoCidades {
	populacaoTotal += populacao
}
fmt.Println("População total somada:", populacaoTotal)
```

Este padrão é extremamente comum para evitar o erro de "variável declarada mas não utilizada" quando você intencionalmente não precisa de um dos valores retornados pelo `range`.
