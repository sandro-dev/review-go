# **3.10: Removendo Itens de um Map**

Após aprender a criar, ler e atualizar dados em um map, a última operação fundamental que precisamos dominar é a de **remoção**. Go nos fornece uma função nativa, clara e direta para realizar essa tarefa: `delete`.

## 1\. A Função Nativa `delete`

Para remover um par chave-valor de um map, utilizamos a função `delete`. Sua sintaxe é muito simples e legível.

**Sintaxe:** `delete(nomeDoMap, chaveParaRemover)`

  * **`delete`:** A palavra-chave da função.
  * **`nomeDoMap`:** O primeiro argumento é a variável do map do qual você deseja remover um item.
  * **`chaveParaRemover`:** O segundo argumento é a chave do item que você deseja excluir.

## 2\. Exemplo Prático: Removendo uma Cidade

Vamos usar o exemplo da aula para ver a função em ação.

```go
package main

import "fmt"

func main() {
	// 1. Nosso map inicial com três cidades
	populacaoCidades := map[string]int{
		"São Paulo":    10000000,
		"CG":           700000,
		"Rio de Janeiro": 6000000,
	}
	fmt.Println("Map original:", populacaoCidades)

	// 2. Usamos a função delete para remover o item com a chave "Rio de Janeiro"
	delete(populacaoCidades, "Rio de Janeiro")

	// 3. Imprimimos o map novamente para ver o resultado
	fmt.Println("Map após deletar 'Rio de Janeiro':", populacaoCidades)
}
```

**Saída:**

```
Map original: map[CG:700000 Rio de Janeiro:6000000 São Paulo:10000000]
Map após deletar 'Rio de Janeiro': map[CG:700000 São Paulo:10000000]
```

Como podemos ver, o par `Rio de Janeiro: 6000000` foi removido com sucesso do map.

## 3\. O "Go Way": A Segurança da Operação `delete`

Uma característica importante e segura da função `delete` em Go é seu comportamento ao tentar remover uma chave que **não existe**.

Como a aula demonstrou, se você tentar deletar uma chave que não está no map, **nada acontece**. O programa não quebra, não gera um erro, nem um `panic`. Ele simplesmente não faz nada.

```go
// (continuação do código acima)

fmt.Println("\n--- Tentando deletar uma chave inexistente ---")
fmt.Println("Map antes de tentar deletar 'XP':", populacaoCidades)

// A chave "XP" não existe no map. Esta operação não fará nada.
delete(populacaoCidades, "XP")

fmt.Println("Map depois de tentar deletar 'XP':", populacaoCidades)
```

**Saída:**

```
--- Tentando deletar uma chave inexistente ---
Map antes de tentar deletar 'XP': map[CG:700000 São Paulo:10000000]
Map depois de tentar deletar 'XP': map[CG:700000 São Paulo:10000000]
```

O map permanece inalterado. Essa característica simplifica o código, pois você não precisa verificar se uma chave existe antes de tentar deletá-la, a menos que sua lógica de negócio exija saber se a exclusão realmente aconteceu.

## 4\. Resumo das Operações em Maps

Com esta aula, completamos as quatro operações básicas que você precisa saber para manipular maps de forma eficaz:

| Operação | Descrição | Sintaxe / Exemplo |
| :--- | :--- | :--- |
| **Criar (Create)** | Adicionar um novo par chave-valor. | `meuMap["novaChave"] = 10` |
| **Ler (Read)** | Obter o valor de uma chave. | `valor, ok := meuMap["chaveExistente"]` |
| **Atualizar (Update)** | Mudar o valor de uma chave existente. | `meuMap["chaveExistente"] = 20` |
| **Deletar (Delete)** | Remover um par chave-valor. | `delete(meuMap, "chaveExistente")` |
