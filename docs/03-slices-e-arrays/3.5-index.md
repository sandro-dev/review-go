# **3.5: Criando Sub-Slices (A Operação de Slicing)**

Na aula anterior, aprendemos a criar uma sub-lista (um novo slice) filtrando os elementos de um slice original com base em uma regra. No entanto, muitas vezes, nosso objetivo não é filtrar por valor, mas sim selecionar um **intervalo de elementos com base em suas posições (índices)**. Go oferece uma sintaxe nativa, concisa e eficiente para fazer exatamente isso, conhecida como **slicing**.

## 1\. A Operação de Slicing (`[low:high]`)

A sintaxe fundamental para criar um sub-slice é `slice[low:high]`. Ela nos permite extrair uma porção do slice original.

**A Regra Mais Importante:**
A operação `slice[low:high]` cria um novo slice que inclui o elemento no índice `low`, mas **exclui** o elemento no índice `high`.

Pense nisso como "elementos do índice `low` até, mas não incluindo, o índice `high`".

**Visualização:**
Dado o slice: `lista := []int{2, 10, 9, 4, 1, 8}`
Índices:          `0,  1, 2, 3, 4, 5`

`lista[1:4]` -\> Pega os elementos dos índices 1, 2 e 3. O elemento no índice 4 (`1`) é o ponto de parada e não é incluído. O resultado seria `[10, 9, 4]`.

## 2\. Atalhos de Sintaxe

Go oferece atalhos convenientes para os casos mais comuns de slicing, como demonstrado na aula.

### a) Pegando os Primeiros N Elementos (Omitindo o Início)

Para pegar todos os elementos desde o início até um determinado ponto, você pode omitir o primeiro índice.

**Sintaxe:** `slice[:high]` (é um atalho para `slice[0:high]`)

```go
package main

import "fmt"

func main() {
	listaToda := []int{2, 10, 9, 4, 1, 8, 3}

	// Pega todos os elementos do início até, mas não incluindo, o índice 3.
	// Ou seja, pega os elementos nos índices 0, 1 e 2.
	primeirosTres := listaToda[:3]

	fmt.Println("Lista original:", listaToda)
	fmt.Println("Os 3 primeiros elementos:", primeirosTres)
}
```

**Saída:**

```
Lista original: [2 10 9 4 1 8 3]
Os 3 primeiros elementos: [2 10 9]
```

### b) Pegando do Índice N até o Final (Omitindo o Fim)

Para pegar todos os elementos de um determinado ponto em diante até o final do slice, você pode omitir o segundo índice.

**Sintaxe:** `slice[low:]` (é um atalho para `slice[low:len(slice)]`)

```go
// (continuação do código acima)

// Pega todos os elementos a partir do índice 4 (inclusive) até o final.
aPartirDoQuarto := listaToda[4:]

fmt.Println("A partir do 4º índice:", aPartirDoQuarto)
```

**Saída:**

```
A partir do 4º índice: [1 8 3]
```

## 3\. Acessando o Último Elemento

A aula mostra uma maneira inteligente de pegar o último elemento, especialmente quando o tamanho do slice é dinâmico.

### Forma 1: Acessando o Valor (Mais Comum)

Para obter apenas o **valor** do último elemento, a forma mais idiomática é acessar o índice diretamente.

`ultimoValor := listaToda[len(listaToda)-1]`

```go
listaToda := []int{2, 10, 9, 11}
ultimoValor := listaToda[len(listaToda)-1] // len(listaToda) é 4. 4-1 = 3. Acessa listaToda[3].
fmt.Println("O valor do último item é:", ultimoValor) // Saída: 11
```

### Forma 2: Criando um Slice com o Último Elemento (Como na Aula)

A técnica mostrada na aula usa a sintaxe de slicing para criar um **novo slice** que contém apenas o último elemento.

`ultimoItemSlice := listaToda[len(listaToda)-1:]`

```go
listaToda := []int{2, 10, 9, 11}
ultimoItemSlice := listaToda[len(listaToda)-1:]
fmt.Println("Slice com o último item:", ultimoItemSlice) // Saída: [11]
```

A primeira forma retorna um `int`, enquanto a segunda retorna um `[]int`.

## 4\. O "Go Way": Slices São "Visões" (Compartilhamento de Memória)

Este é um conceito avançado, mas **crucial**. Quando você cria um sub-slice, Go **não copia os dados**. O novo slice é apenas uma "visão" ou uma "janela" que aponta para o **mesmo array subjacente** do slice original.

Isso torna a operação de slicing extremamente rápida e eficiente em termos de memória, mas também significa que se você modificar um elemento no sub-slice, **a modificação também será refletida no slice original**.

**Exemplo de Demonstração:**

```go
package main

import "fmt"

func main() {
	numeros := []int{10, 20, 30, 40, 50}
	fmt.Println("Original antes:", numeros)

	// Cria um sub-slice do meio
	subSlice := numeros[1:4] // Contém [20, 30, 40]
	fmt.Println("Sub-slice antes:", subSlice)

	// Modifica o primeiro elemento DO SUB-SLICE
	subSlice[0] = 999

	fmt.Println("Sub-slice depois:", subSlice)
	fmt.Println("Original DEPOIS da modificação no sub-slice:", numeros)
}
```

**Saída:**

```
Original antes: [10 20 30 40 50]
Sub-slice antes: [20 30 40]
Sub-slice depois: [999 30 40]
Original DEPOIS da modificação no sub-slice: [10 999 30 40 50]
```

Observe como alterar o sub-slice também alterou o slice original. Tenha sempre isso em mente ao trabalhar com sub-slices.
