# **3.2: Trabalhando com Coleções - Slices em Go**

Com a base teórica estabelecida, esta aula nos mostra como criar, acessar e manipular coleções de dados em Go. A estrutura de dados que a aula introduz como "lista" é, na terminologia de Go, uma das mais poderosas e comuns: o **Slice**.

## 1\. Criando e Inicializando um Slice

A forma mais direta de criar um slice e já preenchê-lo com valores é usando a sintaxe de *literal composto*.

**Sintaxe:** `nome := []Tipo{valor1, valor2, valor3, ...}`

  * `[]Tipo`: Define que estamos criando um slice de um determinado tipo (ex: `[]int` para inteiros, `[]string` para textos).
  * `{...}`: Dentro das chaves, fornecemos os valores iniciais da nossa coleção, separados por vírgula.

**Exemplo Prático (da aula):**

```go
package main

import "fmt"

func main() {
	// Criação e inicialização de um slice de inteiros.
	// O Go infere o tipo de 'lista' como []int.
	lista := []int{4, 9, 6, 7}

	// Imprime o slice inteiro.
	fmt.Println("Slice completo:", lista)
}
```

**Saída:**

```
Slice completo: [4 9 6 7]
```

Como a aula aponta, `lista` não é mais uma variável simples que armazena um único valor, mas sim uma estrutura que agrupa múltiplos valores.

## 2\. Acessando Elementos por Posição (Índice)

Para recuperar um valor específico de dentro do slice, utilizamos sua posição (índice) com a sintaxe de colchetes `[]`, lembrando sempre que **a contagem começa em 0**.

`nomeDoSlice[indice]`

**Exemplo Prático:**

```go
package main

import "fmt"

func main() {
	lista := []int{4, 9, 6, 7}

	// Acessando os elementos individualmente
	posicao0 := lista[0] // Primeiro elemento
	posicao1 := lista[1] // Segundo elemento
	posicao2 := lista[2] // Terceiro elemento

	fmt.Println("Valor na Posição 0:", posicao0)
	fmt.Println("Valor na Posição 1:", posicao1)
	fmt.Println("Valor na Posição 2:", posicao2)
}
```

**Saída:**

```
Valor na Posição 0: 4
Valor na Posição 1: 9
Valor na Posição 2: 6
```

## 3\. Obtendo o Tamanho do Slice com `len()`

Assim como usamos `len()` para obter o número de bytes/caracteres em uma string, usamos a mesma função para obter o número total de elementos em um slice.

**Exemplo Prático:**

```go
package main

import "fmt"

func main() {
	lista := []int{4, 9, 6, 7}
	tamanho := len(lista)

	fmt.Println("O tamanho da lista é:", tamanho)
}
```

**Saída:**

```
O tamanho da lista é: 4
```

## 4\. O Erro Comum: "Index Out of Range"

A aula demonstra de forma clara o que acontece quando tentamos violar a regra fundamental `último_índice = tamanho - 1`.

  * Nosso slice tem **tamanho 4**.
  * Portanto, os índices válidos são **0, 1, 2 e 3**.
  * Tentar acessar `lista[4]`, `lista[5]` ou qualquer outro índice fora desse intervalo resulta em um erro em tempo de execução que interrompe o programa (um `panic`).

**Exemplo do Erro:**

```go
package main

func main() {
	lista := []int{4, 9, 6, 7}
	// A linha abaixo causará um 'panic'
	fmt.Println(lista[5]) 
}
```

**Saída do Erro:**

```
panic: runtime error: index out of range [5] with length 4
```

O compilador nos informa exatamente o problema: "índice fora do intervalo [5] com um tamanho de 4". Esta é uma das mensagens de erro mais comuns que você encontrará ao trabalhar com coleções, e é crucial saber identificá-la.
